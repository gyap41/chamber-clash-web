# 残り武器・レリックの制作指示

30武器（0〜19・28〜37）と26レリック（9〜34）の生成指示を準備済み。武器は試作と同じ2×2配置で8枚、レリックは3×3配置で3枚、計11枚。末尾の空きセルは無地にする。[全ID・送信名・参照画像](plan.json)。11件のプロンプト容量、参照PNG規格、未使用出力名をローカル検証済み。既存CLIの `--check` は現在の予算上限で停止するため、枠拡張承認後に改めて実行する。送信はまだ行っていない。

今回の継続指示に基づく制作準備。既存の累計48回上限を超えるため、生成前に11回分の枠拡張を確認する。承認された場合は累計最大59回、CLIの回数・保守予約上限を60（到達前停止）とする。追加の保守予約は11ドル。直近の同条件3枚は約0.332ドルだったが、次回の請求額を保証する値ではない。自動再送・追加候補は含まない。

生成後は原画・履歴を保存し、透過切り出し、小型表示確認、武器別の大きさ・握り点・銃口点の設定を経てゲームへ統合する。武器の性能やレリックの効果は変えない。

既存7武器の戦闘サイズは、スカウトニードル1.10倍、ガードリベット1.15倍、ミニガトル1.25倍、他4種1.00倍へ調整済み。UIは枠内の表示を維持。握り点・銃口・回避非表示のテストと実描画確認を実施。
