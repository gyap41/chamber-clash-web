# 炉守りの管理機：戦闘とパーツの試作

区分: 本編の仮実装。正式素材・手動受入前。[現行仕様](../../../design/GAME_RULES.md)、[ボス制作案](../../../planning/ENEMY_BOSS_ART_PLAN.md)。

仕様票: ID furnace_warden、機械系ボス。HP48/身体半径44px、表示は幅180px前後・高さ150px程度。通常カメラ倍率1、足元原点。突進・大槌・連射・全周衝撃波・扇射と段階変化、1.5秒起動、踏破まで接続。絵の外接矩形を身体判定には使わない。

[送信プロンプト](../../../../assets/generated/foundry-spinner-v1/prompts.json)、[原本SHA256](../../../../assets/generated/foundry-spinner-v1/manifest.json)。画像編集・切出しなし。PNGはRGBAで透明画素を含むことを検査済み。本体とVFXには広い半透明の色/発光が残って見えるため、暗い床・明るい床で縁とハローの確認が必要。

組立方針: 接地影→奥側装甲→台座/炉心→手前装甲→発光/VFX。注ぎ口は非対称のため左右単純反転禁止。台座は見下ろし投影なので画像全体を平面回転させず、回転コマまたはリング専用表現を追加する。通常から暴走への開閉中間姿勢、突進時の傾斜、撃破推移は本原画だけで完成扱いにしない。炉心・外装の寸法とピボットを登録し、隠れる接続面を補完する。

演出対応: 待機=炉内明滅、移動=台座の回転、突進=傾斜と擦過火花、連射=射出口閃光/反動、落下=持上げ→着地粉塵、全周攻撃=衝撃波、暴走=装甲展開/排熱、撃破=炉の消灯/破片/残骸。独立した排熱煙ループと炉光マスクは未制作。発射後の煙はVFX2行目に含まれる。VFXの拡大縮小だけから攻撃判定を生成しない。特に原画の衝撃波は楕円だが現行判定は世界座標の円なので、そのまま画面全域に拡大して流用せず円形の判定位置へ合う描画を作る。

未確認: 通常倍率の本編表示、全方向・連続動作、切出し境界、透過縁、部品の接続、エフェクト重複時の視認性と負荷、音との同期。素材生成を本編反映・アニメーション完成とは扱わない。

## 独楽の鋳造機の本編接続（2026-09-23）

ユーザーがBGM改訂04を暫定採用し、ボス制作を依頼。本体8方向/状態セル、撃破残骸、生成VFXの閃光と着地粉塵を本編接続。表示名は独楽の鋳造機、内部ID furnace_wardenは保持。原画はassets/generated/foundry-spinner-v1を維持し、同一バイトのランタイム用コピーをassets/sprites/boss/foundry-spinnerへ配置（生成原本ディレクトリはGodot対象外）。画像編集なし。描画コードのRect2がアトラス参照レシピ。

本体セル384×512、描画192×256、正常行の左上(-96,-218)、暴走行(-96,-197)、接地原点(0,0)。正面/右/背面/左を角度で選び、左右反転なし。暴走への変化は1.2秒の画像ブレンドで、独立した装甲ヒンジの完全リグではない。台座の回転は前面を周回する発光点、突進の傾き、擦過火花で表現。上面投影を壊す全身画像回転は行わない。落下攻撃は持ち上げと着地粉塵、既存の前方扇形判定を弧で示す。攻撃判定と威力は維持。

粒子はActor内の最大48個の寿命付きプール。戦闘dtでのみ更新し、独立した常時_processを持たせない。突進火花は0.3秒、暴走煙は0.7秒。Actor退役で残存粒子も解放。撃破表示は従来の独立death_visualの破片と残骸退色を使用。衝撃波は世界座標の円を直接描画し、原画の楕円リングは不使用。生成パーツの個別装甲/炉心と擦過火花シートも現時点では不使用。

音: ボス室入場でfw_spinner_boss_04を-23dB、退出/死亡/踏破/再挑戦は既存コンテキスト管理に従う。96秒末尾の減衰を数値確認し、仮ループ終端92秒。音楽的な継ぎ目は未試聴。重厚SE再生成失敗分と未採用のspinner_01 SEは接続せず、既存heavy_dodge/landing/rapidを仮接続。正式SEは残課題。

### 衝撃波の質感強化

輪を明るい細い先端・橙の帯・内側の揺らぐ残光の4層へ変更。既存生成VFXの着地粉塵4コマを輪の後方へ小さく配置し、短い火花・石粒を重ねる。内部は塗りつぶさない。判定コード・速度・ダメージは変更なし。先端の揺らぎは最大約1.4px、装飾は内側32px程度。円周分割上限512、粒子配置上限96/輪、粉塵はその半数かつ画面外を省略。戦闘の描画時間に同期するためポーズで停止。boss_pressureの描画と回避・同輪再被弾防止テストを確認。Web/低性能端末の実測は未確認。

### 跳躍と機械的な暴走移行

後続修正で全身クロスフェードを廃止。1.2秒の移行中は振動→0.35秒後から炉心・台座・4装甲で組立表示→方向別暴走画像へ接続。装甲参照は原画各列x=index*362+8,y=420,w=346,h=310（隣接セル混入を避ける）。追加生成なし。既存パーツには方向別の完全なヒンジ形状がないため、移行中の組立は共通の見下ろし姿勢であり、全方向独立リグの完成とは扱わない。

衝撃波ごとに0.65秒の跳躍と着地を実装。最大65px持ち上げ、影を接地位置に残し、着地時に輪/粉塵/SEを同期。最終発生後は輪の寿命待ちをやめ、0.4秒で復帰へ移行。半径44pxの障害物迂回と併せてboss_pressureで検証。通常敵・ボス戦回帰テスト通過。ユーザーの具体的なスタック場面との一致と全方向の連続動作評価は未確認。

### 演出レビューの対応（現行）

- 撃破：即時の内部爆発、0.22秒の追加爆発、0.55秒の主爆発・装甲6片、粉塵と残骸退色。表示寿命2.65秒。光球/火花はコード描画、破片は既存partsの装甲セル、粉塵はeffects最下段を再利用。原本変更・追加生成なし。判定/報酬は待たせず、結果パネル/勝利音だけ2.5秒後。
- 音響：生成済みの突進・着地・暴走・排圧・内部/主爆発を接続。エンジン専用1枠、距離減衰、ポーズ/ミュート/退役停止。音量は仮値、音の採用状況はAUDIO_BIBLEが正本。
- 突進：短い加速と制動、回転表示の追従、傾き。構えの沈み込みと復帰の揺り戻しを追加。既存の壁衝突と攻撃順序は維持。
- 連射：反動を追加し、弾と閃光を方向52pxの同一原点へ統一。実際に射出できた連射のみ音/閃光を出す。
- 暴走：中間だけ共通正面のパーツへ変わる方式を廃止。方向別の通常/開放姿勢を振動・炉心発光・排圧煙でつなぐ。全方向ヒンジリグは未制作であり、連続的な装甲開閉の完成とは扱わない。初期の共通パーツ展開の記録は旧方式。

boss_pressure、furnace_warden、boss_activity、exploration_encounter、追加boss_presentationのアサーション通過。描画版で方向別移行4枚と爆発を保存し、正面の中央切れ目や結果パネルによる遮蔽を修正した。通常倍率の静止画確認は実施。連続動作のユーザー受入、音響試聴、Web/低性能環境負荷は未確認。終了時ObjectDB/Resource警告は継続課題。
