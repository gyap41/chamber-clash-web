# 接続用壁材セット v2

目的は、壁の正面が突然柱へ切り替わること、縦横の上面の接合に金属縁が残ることの解消。原本を保存し、4区画をAtlasTextureで参照する。切り抜きの再生成や原画への破壊的編集はしない。

| 部品 | 原本の範囲 | 用途 | 必須条件 |
| --- | --- | --- | --- |
| top.tres | 0,0,512,512 | 全方向で共通の壁上面 | 縁なし・陰影方向なし・一定尺度 |
| face.tres | 512,0,512,512 | 室内へ向いた壁正面 | 柱なし・一定尺度の石積み・反復可能 |
| edge.tres | 0,512,512,512 | 外周だけに置く細い金属縁 | 材質のみ。輪郭はコード側 |
| end.tres | 512,512,512,512 | 開口部などで露出する壁端 | 正面と石段の高さを合わせる |

原本: assets/generated/fw-wall-materials-v2.png。参照定義: assets/first-workshop/wall-kit-v2/。プロンプトは[prompt.txt](prompt.txt)。既存API用CLI、gpt-image-2/high/1024×1024、参照画像なし、1送信のみ。

L字・T字・十字・内角・外角は独立した完成画像を生成せず、矩形上面の和集合と外周バンドで形状を作る。模様は部屋座標に固定し、縦壁素材の回転・部品ごとの引き伸ばしをしない。正面両端の自動柱は描かず、露出端だけに同尺度の狭い側面を付ける。

必要な将来部品: 開閉する扉と封鎖表示は別用途。斜め壁、曲面、異なる高さが連続する立体建築、壁全体のYソートは本セットの対応外。

生成成功。usage換算推定$0.106578、累計78送信。原本は指示の4段より細かい約8段の石積みだったため、表示周期を144×128pxとして1段約16pxに調整する。新規候補は生成しない。

実行用materials.pngは原本のバイト一致コピー。4つのAtlasTextureが参照し、manifest.jsonへSHA-256・切出し領域・表示周期を記録した。工房と四方向検証室へ適用し、接合部の内部縁と柱への切替を解消。room-preview.pngとfour-way-preview.pngを参照。素材の完全なピクセル周期一致は未保証だが、ゲーム実寸で反復と接合部を確認した。追加生成は完了。
