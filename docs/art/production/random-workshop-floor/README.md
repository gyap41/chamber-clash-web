# ランダム工房階層（P2試作）

## 仕様票

- 生成版1、1階層10室（生成APIは8〜12室）。開始・宝箱予定地・ショップ予定地・ボス予定地各1室、残りは通常作業室。敵・宝箱開封・ショップ営業・ボス戦は未実装。
- 見下ろし正投影、通常リナ、1120×800表示、部屋1120×600、倍率1。床(128,128,864,384)、外周壁厚32px、北壁48px、描画高さ36px。
- 北南開口144px、東西112px。到着点は扉から室内へ100px。WorkshopRoomShellの四方向開口を共通利用。内部の接合線隠しの柱は置かない。
- private RNGで隣接セルへ1室ずつ接続。重複セルなし、開始からボス予定地まで経路あり。単一高さの矩形部屋のみ。
- layout0/1は開始工房/隣室の配置を再利用、layout2は0から金床・パレットを除外、layout3は1から作業台・資材箱を除外。北開口時は背面影のある壁付き設備、南開口時は作業台を除き、到着位置を確保する。出口用壁灯は流用しない。

## 必要素材・原本・レシピ

追加生成・画像加工なし。workshop_showcaseテーマ（床、wall-kit-v2上面/正面/外周縁/露出端、室外基礎、扉敷居）と既存StagePlacement（棚82×100、作業台134×61、炉112×132、資材箱72×57、金床68×40、パレット88×58、北壁灯27×44）を流用。器具の取付、影、床の煤/擦れ、光源、衝突は元配置の設定を継承。

素材原本・切出し・透過処理・manifestは[工房](../workshop-showcase/README.md)、[接続壁](../wall-kit-v2/README.md)、[隣室](../workshop-annex/README.md)。必要な扉封鎖、宝箱・ショップ・ボス目印は機能追加時の残素材。現時点では部屋名とマップで予定地を示す。
