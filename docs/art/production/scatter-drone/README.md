# 浮遊散弾機：戦闘試作と素材台帳

区分: 制作記録。状態: 仮パーツ表示で本編接続済み、正式素材・連続動作の受入は未完了。現行動作は[GAME_RULES](../../../design/GAME_RULES.md)、手順は[TESTING](../../../development/TESTING.md)。

## 仕様票

- ID scatter_drone。古い工房の浮遊機械。既存の棘背ヤマアラシの単発扇状弾に対し、時間差で隙間の位置が変わる2波を担当。
- 比較対象: scripts/combat/quillback.gdの5方向攻撃、scripts/visuals/enemy_sheet_visual.gdの番機。既存敵の全品質が採用済みという意味ではない。
- 表示約64×58px、足元原点(0,0)、半径20px。浮遊の影と上下動で支持を表し、歩行コマは不要。移動衝突は通常敵と共通で壁を越えない。
- 仮表示は胴・左右フィン・独立砲口・発光・影。全方向へ砲口を向ける。1.1秒の構えでフィンを開き、各発射に反動、硬直で閉じる。被弾明滅、撃破時の落下・退色・機械粒子まで接続。
- 2波とも構え開始時の方向が基準。2波目は+0.14rad。照準を再追尾しない。入場待機1.6秒、5発×2波、間隔0.48秒、最終発射表示0.48秒、硬直1.8秒。
- 実装: scripts/combat/scatter_drone.gd、scripts/visuals/scatter_drone_visual.gd。弾の原本はprojectile_art.gdのコード描画。
