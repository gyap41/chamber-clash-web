## 制作規格

- 壁床シート：1024×1024、512×512の4区画。床、壁正面、壁上面、角柱。
- 家具シート：同寸法の4区画。炉、作業台、工具棚、壁灯。白背景から輪郭外を除去して透過PNGへ派生。
- 基準床：256pxの繰り返し区画に4×4の石板、石板1枚あたり約64px。
- 壁：現在の衝突形状を維持。正面素材の反復144px、上面の反復48px。
- 家具：足元を基準に描画寸法と衝突範囲を独立指定。接地影はゲーム側で描画。
- 照明：炉1か所、壁灯3か所。光源半径・強さ・位置を配置データで指定。
- 炉は北、作業台は南西、棚は北東。中央から東の出口までの通路を残す。
