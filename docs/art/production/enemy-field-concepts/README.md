## 画風の再評価（2026-09-28）

ユーザー指摘を受け、3体ともリナより階段状の輪郭・陰影が強いと再評価。**画風は要修正**。生成指示の pixel-readable がドット絵寄りに誘導した可能性がある。元の生成指示・PNG・比較画像は履歴として維持する。

種族・配色・体格の案と描き方の採用を分ける。リナを全素材の基準にする方針が確定したため、次は1体を滑らかな暗色輪郭・整理した色面・少ない陰影で描き直し、原画と床上表示を比較する。その結果から残り2体を展開する。以下の床との配色・体格の所見は、画風一致の合格を意味しない。

## 静止比較の所見・残課題

- 甲虫: 青緑と明るい甲殻縁で暗い床から識別できる。根と水場に合わせやすく、尾・丸い棘背を持つ既存生物と形が重複しない。6脚の接地順と素早い停止・噛みつきは未制作。
- イノシシ: 88pxの幅と明るい岩殻で、通常敵より大きい脅威が読める。根や瓦礫との材質の共通点がある。四足歩行・突進時の低姿勢、狭所での足と移動判定の整合が必要。
- 環砲機: 柱・石床と青銅の設備に調和し、三脚で生物2体と区別できる。表面の描き込みがリナより多いので、動画では細部のちらつきを確認する。閉じた砲環区画は原画だけで正確な90度の安全方向を保証できない。砲環を別パーツ化し、現行の発射角・方向固定と一致させる必要がある。
- 自動確認: 実在3室への切替、透明原画の読込、配置点の床・障害物チェック、3枚の書出しがPASS。Godotのユーザー領域ログ／shader cache／証明書の制限警告は発生したが、描画と保存は完了。
- 素材の不足: 3体の方向別歩行・攻撃・復帰・撃破、環砲機の砲環と脚のパーツ、生物用の動作音。今回の静止比較を連続動作の合格とは扱わない。

### 甲虫v3の結果・レビュー

内蔵imagegenで1枚生成。[原画v3](../../../../assets/generated/enemy-field-concepts/root-runner-v3.png)と[生成指示・寸法・ハッシュ](../../../../assets/generated/enemy-field-concepts/root-runner-v3.json)を保存。1254×1254、alpha > 0.1の表示範囲(126,183,1032,898)。原画の加工なし。

- 原画では左右3本ずつの足先が分かれ、細い触角と小さな顎を識別できる。奥の後脚の付け根は甲殻に隠れるため、関節制作では隠れた部分の補完が必要。静止原画だけで歩行可能な骨格が確定したとは扱わない。
- 胴を細長くし、白い反射を除き、縁を細い黄土色に変更。v2より軽快な輪郭と落ち着いた質感になった。リナ基準の滑らかな描き方を維持。
- 3室・通常倍率を目視確認。同じ外接幅48でも脚の張り出しが増えたため、胴はv2より小さく見える。小型の走行敵としては識別できるが、小さな顎・脚の細部は通常倍率では弱い。噛む攻撃の伝達は今後の構えと動作で補う必要がある。
- 比較は左からリナ・v2・v3。[貯水槽](cistern-beetle-v3.png) / [根の広間](root_hall-beetle-v3.png) / [列柱](colonnade-beetle-v3.png)。1120×800、カメラ1.2。再撮影はコマンド末尾へ `-- --beetle-v3`。
- 3室の透過画像読込・床上配置・書出しPASS。ユーザー領域ログ等の既知環境警告あり。ドキュメントリンク検査も実施。
- 本編・Visual Hubの敵表示には未接続。歩行・攻撃・撃破・SEは未制作、ユーザー採用は未確認。追加素材は六脚の接地順・隠れた付け根・顎の開閉を設計してから制作する。
