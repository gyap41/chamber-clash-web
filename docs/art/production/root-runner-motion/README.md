### 足運びの修正

ユーザーの「足の動きが変」という指摘を受け、脚の付け根と接地位置を胴の下へ移動。旧10+10の二節IKは足先が股へ近づくと膝が大きな円弧を描き、丸い体では足がぶら下がって見えていたため廃止。現行は股から足先へ55%の位置に外側1.5pxの曲げを足す短い関節。甲羅で付け根を隠し、足先の描画寸法は6pxのまま。

待機は左右対称の接地から開始。踏出しは歩行位相の境界で開始するが、開始後の足運びは各脚が持つ進行度で完了させる。停止時の着地中に再開しても全体の位相へ飛び戻さない。振出しの進行速度も移動距離に応じて制限し、停止時は持上げ高さを現在値から0へ下ろす。歩行速度72px/s・タックル性能は変更なし。追加生成は不要、既存素材で修正した。

[歩行→停止の確認動画](walk-motion.webp)は4.8秒・144フレーム、その場の足運びを1.1秒歩行/0.5秒停止で3回表示。通常1.2倍と4倍を併記。タックル動画も修正版で再撮影。60/120Hzの短い停止・再開を各600tick反復し、足先/膝のフレーム間移動上限と支持脚の静止を確認。見た目の最終採用はユーザー未確認。
