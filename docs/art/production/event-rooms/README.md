## コードで作った演出（2026-09-30）

ユーザーの選んだ「1. コードで作れるもの」を実装した。新しい画像・SEの生成はしていない。共通の演出ノードは [event_fx.gd](../../../../scripts/visuals/event_fx.gd)。床の下に描く層（輪・警告円）と、キャラより上に描く層（柱・粒・文字、画面の表示と明滅）の2つを使う。時間はゲームの更新からだけ進むので、停止中は途中の形のまま止まる。部屋を移ると消える。待機中の粒（転送装置・祭壇の炎）は、時間から位置を計算する方式で、状態を持たない。

|対象|演出|
|---|---|
|硬貨|倒れた位置から跳ねて着地（0.35秒、着地するまで拾えない）。敵の残骸より上に描く。拾うと金色の粒と「+nG」、所持金の表示が拡大して光る|
|露店|購入で金色の粒・床の輪・「-nG」、購入音。拒否は拒否音と値札の揺れ|
|祭壇|炎から火の粉。捧げると赤い粒がキャラから鉢へ流れ、赤い光の柱と画面の明滅|
|試練|開始時の金色の輪と警告音、各波の表示、敵の足元の赤い警告円、突破時の表示と粒|
|転送装置|待機中の青い粒。到着時の光の柱・床の輪・粒・画面の明滅と音|

確認画像：[硬貨の取得](fx-coin-pickup.png)・[購入](fx-purchase.png)・[祭壇](fx-altar.png)・[試練の第1波](fx-challenge.png)・[転送の到着](fx-teleport.png)。検証は `tests/exploration_events.gd`（演出の発生、停止中に止まること）。連続した動きの見え方と、戦闘中に邪魔にならないかの確認は、実際に遊んでの確認待ち。

### 対象と方式

- 対象コード：[exploration_events.gd](../../../../scripts/game/exploration_events.gd)（露店・祭壇・試練・転送装置）、[exploration_coins.gd](../../../../scripts/game/exploration_coins.gd)（硬貨）、[event_fx.gd](../../../../scripts/visuals/event_fx.gd)（演出）、[sound.gd](../../../../scripts/audio/sound.gd)（SEの登録）。
- 方式：透過した物の絵を1枚のシートにまとめて生成し、既存のキットと同じく目視で分けた範囲からAtlasTextureを切り出す（[build_exploration_kit.gd](../../../../tools/build_exploration_kit.gd)と同じ手順）。コードで描いている仮の表示を置き換える。演出（粒・柱・輪）はコードのまま残し、光らせる部分だけ別の画像に分けて脈動させる。
- 参照画像（最大3枚）：リナの現行画像（画風の主参照）、既存の探索キットのシート（石・真鍮・木の材質と視点の補助）。

- 1枚の透過シートに8区画を並べる案。シートの区画・余白・背景は生成前にプロンプトで指定し、生成後に抽出範囲とSHA-256を記録する。

### 確認方法

- 通常倍率でリナの横に並べる（奥・横・手前）。硬貨は敵弾が飛ぶ中で見分けられるか。
- 照明あり／なしで、透過の境界・白縁・光る部分の分離を見る。
- 転送装置と試練の台の脈動を連続で再生し、停止中に止まる・部屋を移ると消えることを確認する。
- 衝突を付けた物は、到達性・露店の列・宝箱の配置の自動テストを再実行する。
- 生成済み・本編に接続済み・動作確認済み・ユーザー採用を分けて記録する。
