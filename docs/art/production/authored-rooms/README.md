### B. 当たり判定が絵より小さい（絵の上に重なって歩ける）

- 床置きの物は、当たり判定を「足元の帯」（幅0.86倍×奥行き14〜34px）だけにしている。背の高い物（炉・棚・柱）は、奥側を歩いて後ろに回り込む表現として正しいが、**低い物**（瓦礫・資材箱・パレット・金床・茶の卓・焚き火）は上面がほぼ床の広さなので、上半分にキャラが重なって「絵の上を歩いている」ように見える。
- 焚き火の当たり判定は石の輪の下半分だけ。瓦礫の山も上半分が空いている。

### C. 貼り付け感の原因

1. **床だけを暗くした**: 前回の明暗の調整で床を0.68倍にしたが、置物・壁の素材は暗くしていない。床（明度17）に対して置物が相対的に明るくなり、切り抜いて貼った写真のように浮く（旧鋳造区 v2 の標準の床は明度21）。
2. **置物に影がない・弱い**: 床の装飾として置いた物（鋳造の溝・根・寝具・巣）は影がなく、床置きの物も足元の小さな楕円の影だけ。左上からの光に合わせた、右下へ落ちる影がない。
3. **床の装飾の輪郭が強い**: 小石・ひび・土の帯にも濃い輪郭線があり、床の目地の線と重なって「上に乗ったシール」に見える。
4. **灯りが置物に当たらない**: 光だまりは床に描いた模様なので、灯りの近くの置物も明るくならない。

### D. 室内の壁の断片（オブジェクトのつながり・当たり判定）

- **プレイヤーが壁の上に乗って見える**: 壁は、キャラとの前後を比べずに常にキャラより下に描く設計（`field_builder.gd` で壁の層は z=-10）。外周の壁は部屋の端にあるので問題にならないが、室内に置いた壁の断片は、その後ろ（北側）に立つとキャラが壁の絵の上に重なる。当たり判定（厚さ32px）は壁の足元だけなので、壁の絵（高さ約68px）の上半分に入れる。

### E. 切り欠いた角（ステージのつながり・壁の上面と側面）

- **内側の角で上面が正面を横切る**: 折り返しの縦の壁（上面の素材）が、張り出した壁（正面の素材）の厚みの分まで下に伸びて重なるため、縦の壁の上面の帯が正面の石積みの上を横切って床まで届く（「通路の終端は側壁の厚みまで石積み正面を連続」に反する）。

### 開口の追加

各部屋の開口候補を全組合せで組み立て、①入口・到着点・その間の通路が衝突に塞がれない、②全扉へ到達できる、③扉の周囲に壁付き・床置きの物（装飾の平面を除く）が重ならない、を自動で調べた（調査用スクリプトはコミットしない）。合格した組合せは全体表示で目視し、扉が物の配置や建築の意図と衝突しないことを確認した。

|部屋|許可する開口|北・南を許可しない理由|
|---|---|---|
|回廊・鋳造・野営跡・根の広間・列柱・中庭・荷捌き場・貯水槽・詰所・倒れた大門・巣|北南西東の任意の組合せ|―|
|双広間・補修室|南西東の任意の組合せ|双広間は北の仕切り壁で北口が孤立。補修室は北壁中央に補強材と壁灯|
|収蔵庫（寄り道終点）|北・南・西・東のいずれか1か所|―|
|礼拝室・記録室・展望室（寄り道終点）|南・西・東のいずれか1か所|礼拝室は祭壇と石碑、記録室は石板の列、展望室は地底の開口が北側を占める|
|保管区画・脇室（寄り道終点）|西・東のいずれか1か所|北と南の区画・切り欠きで到達できない|

寄り道終点は元の西東の通過組合せも20室一覧用に維持する。前室は従来どおり。倒れた大門の北口は既存の門柱の間に開く。巣の北口は西側の柱に接するが通行は可能。部屋の配置・絵・衝突は変更していない。
