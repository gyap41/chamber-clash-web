接続点は正式原画制作時に方向ごと確定する。今回は画像・SE生成なし。仮原本はscripts/visuals/sentry_variants_visual.gd。歩行は移動距離同期の脚、構えは工具／板／砲身の変位、被弾は明滅、撃破は落下・退色と機械粒子。仮コード描画のため生成ハッシュ・切出しレシピは対象外。

SEは番機の既存構え・振り下ろし・撃破を仮流用。破砕番機の駆動・停止音、環砲機の発射音は専用化の候補。音の追加生成は行わず、材質・同期・混雑は未試聴。弾は既存の丸いenemy_scatter描画を流用。

## 戦闘・確認

走り番機は高速低耐久の近接。破砕番機は方向固定の突進、接触1回で停止。壁にぶつかった場合も空振りも硬直へ戻る。環砲機はプレイヤーを狙った基準方向に逃げ道を残す環状弾を2波。いずれもボスではなく、ボス報酬・専用イントロはない。

自動確認: 3体の本編生成、突進の命中・空振り・壁停止・多重被弾防止、環砲2波22発と安全方向、画面外中止、パルス、死亡後停止、機械撃破。12seedで3体の実出現と強敵1体上限、出現地点周囲8方向96pxの通行帯を確認。既存トカゲ・ヤマアラシ・散弾機・戦闘ライフサイクルも回帰確認。
