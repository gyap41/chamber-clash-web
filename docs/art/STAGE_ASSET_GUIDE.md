# ステージ素材の制作ガイド

ステージ制作を始める際は、まず[ステージ制作テンプレート](STAGE_CREATION_TEMPLATE.md)を読む。仕様票・必要素材一覧・壁接続の判断・制作手順・完了チェックを共通化している。

工房以外のステージにも適用する、見下ろし型2Dゲームの共通制作基準。画像単体の精細さより、キャラと同じ空間に存在して見えることを優先する。2026-09-22の作業台の視点修正を反映。

## 1. 制作前に決めること

| 項目 | 決定事項 |
| --- | --- |
| 基準キャラ | ゲーム内の通常サイズを使用。家具を合わせるためにキャラを拡縮しない |
| カメラ | 見下ろしの正投影。画面の横辺を水平に保つ。等角投影や透視図を混ぜない |
| 寸法 | 元画像の解像度とは別に、ゲーム内表示幅・奥行き・見かけの高さを記録 |
| 素材の役割 | 床、低い家具、高い家具、壁、装飾、発光部分を区別 |
| 配色・材質 | ステージごとに基調色と補助色を決める。床より人物・弾が見分けやすい明度にする |
| 光 | 素材内の弱い陰影の方向を統一。強い環境光・光だまりはゲーム側で追加 |
| 接続 | 壁の厚み、笠石の幅、正面の高さ、扉の開口幅、床の目地間隔を決める |

## 2. テーブル・作業台・低い遮蔽物の視点

**天板・上面が主体。脚や正面を大きく見せない。** 正面の商品写真のような机を小さくしても、天板がキャラより高い印象は解消しない。

- 作業台では真上から少し手前へ傾けた、強い見下ろしを基準とする。生成指示の目安は床から約70度、真上から約20度。これは素材制作の目安であり、ゲームのカメラに3D角度を設定する意味ではない。
- 天板全体を見せ、手前の板厚と短い側面だけを添える。脚は天板の下へ隠し、長い縦脚や机の下の空間を見せない。
- 道具・図面・バイスも天板と同じ見下ろし角度にする。
- 資材箱・パレット・金床も同じ上面の見え方にする。低い物は正面の帯を短くし、高さを脚で誇張しない。
- 幅、床上の奥行き、高さを分けて考える。画像の縦寸法は「床の奥行き＋見える側面」であり、そのまま物体の高さではない。
- 画像を縦につぶして視点変更の代用にしない。構図が違う場合は描き直す。

工房作業台の今回の生成指示：上面主体、手前の板厚は画像高の約8%以内、足の突出は約3%以内。これらは見本の制約で、全家具へ機械的に適用する寸法ではない。

## 3. 壁・炉・棚など高い物

- 壁や炉は高さを伝える正面を持つが、上面の方向と光は低い家具と整合させる。
- 壁の衝突矩形は床上の占有範囲。表示する高さはそこから上へ伸ばす。高さのために歩ける床を削らない。
- 炉など大型設備はキャラより大きくてよい。日常的に使う机・取っ手・工具まで同じ倍率にしない。
- 炉や棚を壁付きにする場合は、設置位置と背面の影で接続を示す。
- 外角・内角・端部・通路接続を直線素材と一緒に確認する。笠石が途切れたり、違う高さで突き合わされたりしないこと。

## 4. 透過・影・照明

- オブジェクトの輪郭外は透明にする。透過部分の下にColorRect等の不透明な下地を残さない。
- 素材単体に床・強い落ち影・光のハローを焼き込まない。床に描く影とゲーム側の照明を分離する。
- ランプ本体と光源の位置を区別する。金具の基準点が光の中心とは限らない。
- 白背景を除去する工程では、金具や脚の内側に残る白、隣の区画の破片、輪郭の白縁を確認する。
- 原本は保存し、抽出範囲・背景除去条件をmanifestへ記録する。

## 5. 配置と描画順

- 足元中央を基準とし、表示矩形と衝突矩形を別々に持つ。
- 人物が家具の奥・横・手前に立つ3場面で確認する。武器だけが家具を突き抜けて前に見えないこと。
- 影は床へ描く。人物の上に家具の接地影を重ねない。
- 家具を縮小したときは、見えない大きな衝突が残っていないか確認する。
- 出口までの経路、回避の通り道、射線を確保する。装飾と戦闘用遮蔽物を区別する。

## 6. 合格判定

1. 原寸表示のキャラを横に置き、縮尺・使用時の高さ・上面の角度を見る。
2. 床を反復し、壁の四隅と入口を組み立てる。素材単体だけで合格にしない。
3. 人物を奥と手前に移動させて前後関係を確認する。
4. 家具周囲の移動・弾の衝突・扉への到達性を確認する。
5. 照明あり/なしで色・透過境界・影を見る。人物・敵弾が埋もれないこと。
6. 部屋を往復し、家具・光源・影が重複しないことを確認する。
7. 制作条件、採用素材、ゲーム内プレビュー、未確認項目を記録する。

### 開口部の仕上げ

壁の端と扉枠を二重に描かない。壁で開口部が成立している場合は、その石材と厚みを優先する。壁の上面画像を細長く引き伸ばして敷居に使うと柱に見えるため、床の連続性が残る低コントラストの表現にする。短い壁に角材を両端から重ねて四角いブロックを連ねない。壁灯は接合部から離し、取付面を明確にする。

### 炉と壁灯の取付面

室内の炉は煙突の口だけで終わらせず、壁へ入る排煙管または屋根へ続く煙道を示す。壁への接続金具と影を付け、排煙口が室内に開いて見えないようにする。正面用の壁灯は正面の壁面へ配置し、側壁の上面に貼らない。側壁へ設置する場合は、その向きの支持金具・素材を用意する。

### 四方向の開口

扉の向きと開口幅を先に決め、壁矩形と床領域を一致させる。上下の開口に左右用の壁正面を回転して貼らない。北側は正面壁を分割し、南側は手前の笠石を分割する。操作案内は室内側へ配置する。T字接合では同じ位置に角材を二重に置かず、敷居の向き・通路端の当たり判定を四方向で確認する。

### 壁接合の再設計方針（2026-09-22、工房へ適用済み）

従来の接続補正は隙間を塞ぐ処理で、連続した壁面の表現を保証しなかった。側壁の上面を延長して正面壁へ被せること、正面素材を端柱幅へ圧縮すること、縁付き上面を回転・重ね描きすることが、柱への唐突な切替と接合線の原因になる。

次の壁制作では、衝突矩形と描画部品の単位を一致させる必要はない。接続済みの壁の輪郭を先に求め、石の上面の地模様と露出した縁・側面を分けて描画する。隣接壁同士の内部境界には金属縁・終端線・落ち影を描かない。素材の尺度・模様の開始位置を揃え、壁矩形ごとの伸縮で石目を変えない。

必要部品は、縁なし上面、一定尺度の正面、外周用の細い縁、内角・外角・T字用の接続形状、露出した壁端の側面。接続形状はマスクや描画形状で共通化でき、すべてを独立した生成画像にする必要はない。装飾柱は接合部隠しに自動配置せず、必要な場所だけ明示配置する。光の向きが描き込まれた素材を90度回転して流用しない。

受入には、四方向の開口、L字/T字、長短の壁、異なる厚さを同時に並べ、上面の縁が内部を横切らないこと、正面と側面の石目の尺度が揃うこと、接続が柱に見えないことを追加する。衝突・通行のテストと美術上の連続性を別々に確認する。既存の接続テストPASSだけで見た目を完了扱いにしない。

上記を接続用壁材セットv2として実装。必要4素材・表示周期・導入方法は[ステージテンプレート](../development/STAGE_TEMPLATES.md#接続用壁材セット-v22026-09-22)、[生成プロンプトと素材記録](production/wall-kit-v2/README.md)を参照。

壁上面の連続性だけでなく、正面へ回り込む範囲も確認する。通路上壁の床際で終わる側壁は、厚みの部分まで正面材をつなげる。上面で正面を覆って柱に見せない。左右を反転した接続も確認する。

上側の角と下側の終端を区別する。縦壁が下へ続く北壁の角では、上面を北壁の笠石まで連続させる。横壁の床際で縦壁が終わる接合だけ、厚みの部分を正面へ割り当てる。一律に正面優先で上面を切り取らない。
