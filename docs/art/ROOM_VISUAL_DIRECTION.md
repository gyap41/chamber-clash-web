# 探索部屋の空間表現

2026-09-21にユーザーが提示した見下ろし型ダンジョン画像から、空間構成を抽出した。ドット絵への全面変更や画像内のキャラクター・装飾の複製は目的としない。工房の石材・青緑の金属という既存の配色で構成を取り入れる。

| 抽出要素 | 役割 | 対応 |
| --- | --- | --- |
| 壁の上面と室内向きの垂直面 | 高さ・厚みを伝える | 北側の壁と通路上側に、上面＋石積み正面を実装 |
| 暗い室外、室内だけの床 | 部屋の輪郭と移動空間を明確にする | floor_regionsで室内と通路を限定、室外を暗色にする |
| 扉へ続く壁付き通路 | 出入口を建築構造として見せる | 幅112pxの開口部と左右の短い通路を実装、Fで遷移 |
| 凹凸のある輪郭 | 四角い枠から建物の形へ変える | 通路の張り出しを実装。隅の欠き込みや部屋別の変形は後続 |
| 壁際の影 | 壁と床の接地・奥行きを伝える | 床領域内だけに接地影を実装 |
| 暖炉・壁灯と局所的な暖色光 | 視線誘導、空間の雰囲気 | 後続。工房の炉・作業灯として設計する |
| 絨毯・机・樽などの用途別内装 | 部屋の用途・個性を伝える | 後続。工房では作業台・工具・床の作業区画を検討 |
| キャラクターと内装の前後関係 | 遮蔽の自然さと戦闘の視認性 | 今回は壁正面を衝突矩形内に収め、手前壁を低く表示。背の高い家具の並べ替えは後続 |

## 実装と交換方法

FieldDefinitionのwallsは衝突矩形、floor_regionsは床描画範囲。wall_texturesは上面素材、wall_face_texturesは垂直面素材を壁番号で指定する。画像の大きさで衝突形状は変えない。未指定のフィールドは従来の床・遮蔽物の描画を維持する。追加API生成は行っていない。

## 確認範囲

2部屋の描画、扉への歩行到達性、通路側壁・上下外周壁の移動阻止、solid判定、20往復の状態保持、素材交換時の衝突不変性、不正な床領域・壁正面参照の拒否を検証する。家具・局所照明・変形部屋の完成を意味しない。

## 継ぎ目と室外の再検討

細い壁で素材の横断方向を切り取っていたため、金属縁の片側が欠けていた。横断方向は素材全体を収め、長手方向のみ反復する方式へ修正。北壁の両端に角柱、手前壁と通路端に角用の上面を配置し、縦横の接続を補う。既存のcorner-cap素材を利用し、新しいAPI生成は行わない。角材はWallのcorner_textureで交換可能。

室外の候補は次のとおり。

| 案 | 評価 |
| --- | --- |
| 一様な黒 | 移動範囲は明快。壁の輪郭が切り抜きのように見えやすい |
| 暗い基礎＋周囲に薄い陰影、遠方は暗色 | 今回採用。建物の厚みを補い、床との区別も保てる |
| 岩盤・土・屋外地形を広く描く | 地下工房などの設定が決まった段階で検討。現時点では歩ける場所との混同や画面の情報過多を招く |

壁の外側7pxに低明度の石積み、28px以内に弱い陰影を描画。外側は演出のみで衝突範囲・床範囲を変更しない。部屋・左右通路を1120×800の実描画で確認する。

今後の素材は、まず内角・外角・T字接続を同じ上面幅と垂直面高で揃えた壁セットが有効。部屋形状が増える段階で、接続方向をデータから選ぶ方式へ拡張する。次いで工房の壁灯と炉を少量配置し、入口を暖色光で誘導する。家具や床の装飾を増やす前に、弾・キャラクターとの明度差を確認する。今回の修正は継ぎ目と室外に限定する。
