# 通常画面でのモーション視認性

Godot実行時に動きが小さいというフィードバックを受け、8人共通の呼吸・胴体の振り・足運びを強化。
歩行回転は±0.026→±0.065rad、足上げ2.6→4.4px、歩幅の片振幅1.9→3.6px、進行方向への傾き0.045→0.09rad。
呼吸の縦倍率は0.99〜1.012→0.975〜1.028。テンポと状態遷移時間は維持。

起動ウィンドウは1120×600→1120×800。カメラは戦場全体を見渡す倍率を維持。
エディター埋め込み実行では表示パネルの大きさにも左右される。

`battle.gif`は1120×800の実ゲーム描画を拡大せず保存したもの。リナとクロウの待機→移動→停止。
撮影用に移動軌跡を指定し、CPU・戦闘進行を止めているため、実プレイの録画ではない。
GIF表示時にビューア側で縮小される場合は原寸で開く。前回の拡大比較は別フォルダーに保存。
