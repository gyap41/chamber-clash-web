## 原画・処理

[制作指示](../../production/equipment-diversity-2026-09-13/README.md)、[握り点・銃口・倍率](../../production/equipment-diversity-2026-09-13/weapon-layout.json)、[切り出し記録](extraction.json)。原画とAPIメタデータは `assets/generated/fw-diverse-*`、ゲーム用は `assets/first-workshop/equipment/`。

透明化では背景の色差と余白を使い、全面グリッド線と輪郭のマゼンタ残りを除去。紫色のヘリックス内部は保護する。元画像は保存し、構造の描き直しは行っていない。ID11は-90度、14は-45度、2は120度、33は-90度回転。18と28は左右反転して射出・使用側を右へ揃えた。比率を保って縮小し、個別の握り点と銃口位置を設定。ID20は既存サービスピストルを継続使用する。
