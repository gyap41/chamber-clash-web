## 構造

本体・弾・演出はdata/weapon_visuals.jsonへ集約。系統の既定値と武器別の上書きを使う。発射・命中・反射・分裂・装填開始／完了／中断の通知から演出を再生する。装填は実際の残時間に同期し、中断や死亡で止まる。専用シーン、ゲーム上の専用効果を登録する入口も追加した。[追加手順](../../../development/WEAPON_EXTENSIONS.md)。既存特殊挙動の全面書き換えは行っていない。

## 原画と処理

[6シートの制作指示](../../production/projectile-effects-2026-09-13/README.md)。原画とAPIメタデータはassets/generated/fw-projectile-*。各シートの切り出し座標はこのフォルダの*-extraction.json、透過後の比較は*-review.pngに保存。

マゼンタ背景と全幅の区切り線を除去。弾と発射光は縦横比を保って96px以内へ縮小。着弾は余白の境界を探してコマを分離し、同じ行の初光を基準に中心を揃えて128px×4コマへ配置。個別のコマを最大まで拡大せず、膨張と消散のサイズ差を残した。原画は変更せず保管する。
