各画像は拡大図、小型表示、同じ小型表示の4倍拡大を並べる。武器40×30px枠・レリック24×24px枠に縦横比を保って収めた静止比較であり、ゲームでの装備・回転・エフェクトとの重なりを検証したものではない。

docsとassets/generatedは現行Webエクスポート対象外。今回の試作画像は配布ビルドに含まれない。

## 採用後の実装事項

現行の `player.gd:update_weapon_art` はID20以外を40×30へ個別軸で伸縮する。新素材では縦横比を維持し、武器別の握り位置・銃口位置を合わせる必要がある。準備画面、戦闘HUD、地面の武器表示にも同じIDを接続する。レリックはHUDスキンの `relic_00`〜`relic_08` を含む参照先を確認して接続する。

武器30種とレリック26種は未制作。追加生成は今回の3枚に含めない。

## 試作レビュー

武器7種はセルをまたがず、右向きで切り出し可能。針・円盤・太い鋲・二連銃口・ルーンの芯・回転弾倉・大型ドラムで形を分けた。40×30枠では細かな模様は消える。特にスカウトニードルの先端は細く、正式実装時の表示サイズとコントラスト確認が必要。側面図だけで回転弾倉や多連銃身の総数を数えられる表現にはしていない。

レリック9種を透過切り出しし、24px比較を確認。形・色の違いは残るが、ライフアンプのハートや予備マガジンの矢印は24pxでは読み取りにくい。効果の説明は名前・ツールチップを併用する前提。ドッジノヴァと下段のセル境界は原画の空白位置に合わせて調整し、隣接素材の混入を防いだ。

承認どおり3送信・3成功で終了。今回のusage換算推計は$0.331758、送信累計48回（過去の成否不明1件を含む）。請求確定額ではない。既存CLI（gpt-image-2 / high / 1024×1024）を使用し、自動再送なし。予算・重複・失敗停止のPythonテスト6件、16素材の切り出し、整理台帳・リンク検証を通過。ゲームコードは変更しておらず、ゲーム内装備表示の試験はまだ行っていない。
