## 1. 目的と基準の方向

キャラ・敵・ステージが同じ作品に見えるよう、素材の系統ごとに異なっている描き方を一つの基準へ揃える。世界観（灰積もる旧鋳造区、石積み・煤・真鍮・暖色灯）と見下ろし正投影は変えない。

**基準はキャラ側に置く（画風比較のA案寄り）。**

- 8キャラの方向別素材とリナの8方向リグがあり、作り直しの量が最も少ない。
- 見下ろしアクションでは、キャラ・敵・弾が背景より先に読めることを優先する。
- [A案](../planning/art-direction-comps/a-character-led.png)は床の細かい模様を抑えるだけで、既存キャラ・敵・柱がまとまって見えることを示した。ただしA案は構図カンプで、素材の完成見本ではない。

画像単体の見栄えより、**通常のカメラ倍率で他素材と並んだときの揃い方**を合格の基準とする。

## 2. 現状のずれ（2026-09-26時点の診断）

計測の根拠: [同倍率比較シート](reviews/style-comparison-2026-09-26/README.md)（列柱作業室、カメラ1.2倍）。

|系統|現状|基準とのずれ（計測値）|
|---|---|---|
|自キャラ（8方向版リナ）|約2頭身のデフォルメ。濃い輪郭線と平塗りに近い陰影|基準。平均明度44.5、輪郭の対背景差25.2で、全素材中で最も強い|
|通常敵|トカゲ/ヤマアラシは写実寄り、番機は中程度の描き込み|番機28.5・トカゲ31.8が柱34.1より暗い。輪郭の対背景差9.6〜11.6で、柱の13.9より弱い。頭身・質感も写実寄り（目視）|
|ボス|リベット・錆・反射まで描いた描写|平均明度12.5で床の20.5より暗く、明暗差も小さい。細部は多いが、通常サイズでは暗い塊に見える|
|柱・資材箱・金床|石・木・金属の中程度の描き込み|明るさ・輪郭・細部量が敵と同等以上で、背景物の方が目立つ|
|床|石の質感|細部量・ばらつきとも全素材で最小。**過剰ではない**|
|壁の上面・扉・一部の弾|単色の平面、コード描画の図形|仮素材。画風の差ではなく仕上がり具合の差として別に管理する|

主因は**明暗の設計**。背景物がキャラ・敵より明るく輪郭も強いため、動くものが埋もれ、系統ごとに別の絵に見える。ボスは暗さと明暗差の小ささで浮いている。次いで、頭身・質感の決め方（写実寄りの敵）の違い。初版で主因とした「床の細かい模様」は、計測では裏付けられなかった。

前提となる実装: 原画は1000px級の高解像度AI画像で、ゲーム内では線形フィルタで縮小表示する（ピクセルアートではない）。表示領域は1120×800、探索カメラ1.2倍。キャラの全高は通常倍率で約56px。

## 3. 共通規格

### 3.1 描き込み密度

- **基準単位**: 通常倍率でのキャラ全高（約56px）。すべての素材は、この倍率で画面に出たときの見え方で判断する。原画の解像度で判断しない。
- **細部の最小単位（暫定）**: 画面上で約3px（キャラ全高の約1/16）未満の細部は描かない。小さな細部は一つの形にまとめるか、省略する。
- **大きい物の扱い**: ボス・炉など大きい素材も、細部の細かさはキャラと同じ単位に揃える。大きさは形の数ではなく、**大きな形のまとまり**で見せる。例: リベット20個 → 目立つ金具3〜5個、細かな錆の斑点 → 大きな錆の面2〜3か所。
- **動くものと背景の差**: 背景（床・壁）の描き込み密度は、キャラ・敵より**低く**する。逆転させない。

### 3.2 輪郭線

|対象|輪郭|
|---|---|
|キャラ・敵・ボス・拾得物・宝箱|あり。黒ではなく、その部位の固有色を暗くした色。通常倍率で約1.5〜2px相当|
|敵弾・危険なVFX|芯と縁で表現（[3.6](#36-弾vfx)）。輪郭の代わりに明るい芯を使う|
|床・壁・家具・柱|あり。キャラと同じ濃い線の描き方で、線と面の明暗差・彩度を下げる。動くものより必ず目立たせない|

画面全体を同じ「濃い輪郭線＋平塗りに近い陰影」で描く。背景は線をなくすのではなく、彩度と明暗差を下げ、形を大きく単純にすることで奥に下げる（2026-09-26、ユーザー提示の参考動画のゲームで確認。初版の「背景は輪郭なし」から変更）。

### 3.3 陰影と光源

- 素材内の光源は**左上**に統一する（既存の「素材内の弱い陰影の方向を統一」を具体化）。
- 陰影は**影・中間・明部の3段＋ハイライト1つ**を上限の目安とする。写実的な反射、映り込み、細かいグラデーションは使わない。
- 金属は「明部の帯1本＋ハイライト点」で表現し、細かい反射模様で表さない。
- 強い環境光・光だまり・接地影はゲーム側で追加する（[ステージ素材ガイド](STAGE_ASSET_GUIDE.md)の分離規則に従う）。

### 3.4 形と頭身

- **武器は大きく描いてよい（ユーザー決定 2026-09-26）。** 多様な銃を使うゲームなので、武器の形を読み取れる大きさを優先し、体に合わせて縮めない。

- **揃えるのは描き方、敵ごとに変えてよいのは性格（ユーザー決定 2026-09-26）。** アニメ調の線と塗りは全員共通にする。ただし可愛いだけにせず、かっこよさ・威圧感・重厚感は、形・表情・大きさ・発光で出す。

|全員で揃える（描き方）|敵ごとに変えてよい（性格）|
|---|---|
|濃い輪郭線と平塗りに近い陰影（3.2・3.3）|形の輪郭（丸い／角張る／非対称）|
|左上からの光、2〜3段の陰影|頭身と比率（低頭身はプレイヤー側の規則。敵に強制しない）|
|明暗の順序（3.5）|目・口・表情（点の目〜光る細目・牙）|
|細かい模様より大きな形（3.1）|大きさ・重さ・発光部の使い方|

- **敵の格による描き分け**（目安。敵ごとの制作記録で、どの格かを決める）:

|格|例|形・表情|陰影・色|
|---|---|---|---|
|愛嬌のある雑魚|番機、ヤマアラシ|丸く短い手足、点の目|柔らかい2段|
|威圧感のある敵|火袋トカゲ、今後の生物系|前傾・低い姿勢、鋭い爪と牙、細く光る目|影の境目をくっきり、影を濃く|
|重厚な機械・ボス|独楽の鋳造機、今後の大型機械|厚い装甲板、重心が下、少数の大きな部品|深い影色と金属の明部の帯。炉・目の発光で視線を集める|
|異形・クリーチャー|今後の追加候補|非対称、口や目の数を誇張、触手や裂け目|彩度の高い差し色を危険の合図に使う|

- 威圧感は、描き込みを増やして出さない。単純な形のままでも、目つき・口・姿勢・画面に占める大きさ・発光の差し色で出す。例として、ユーザー提示の他作品のボスは、丸い形と平塗りのまま、光る吊り目・牙の口・大きさ・赤で強い威圧感がある（ドット絵の見た目は採用しない）。
- キャラは現行の低頭身デフォルメを基準とする（[キャラ美術定義](../design/CHARACTER_BIBLE.md)）。
- 生物の敵の種族らしさは、写実的な質感ではなく、**輪郭の特徴**（トゲの列、尾の形、口の大きさ）で出す。
- 機械の敵・ボスは、単純な基本形（球・円筒・箱）の組み合わせを主にする。部品の数を増やして複雑さを出さない。
- 形の読み取りは**輪郭だけ（シルエット）**で種類と向きが分かることを条件とする。

### 3.5 色の役割と明暗の帯

|役割|明暗|彩度|備考|
|---|---|---|---|
|床|暗い〜中間の狭い範囲|低い|明暗差の小さい大きな模様。細かな明暗の粒を作らない|
|壁・柱・家具|床より一段明るい、または暗い|低〜中|床との境界は明暗差で示す|
|キャラ・敵|中間〜明るい、明暗差が大きい|中〜高|輪郭を含め、床の上で最も目立つ層|
|敵弾・危険表示|最も明るい|高|暖色（橙〜黄）を危険専用に予約する。背景の照明や装飾に同じ強さで使わない|
|拾得物・報酬|明るい|中〜高|敵・敵弾と混同しない色相。種類ごとの割当は比較シートで決める|

暫定の目標値（[比較シート](reviews/style-comparison-2026-09-26/README.md)と同じ計測方法。ユーザー採用前）:

|対象|平均明度|明度のばらつき|輪郭の対背景差|現状|
|---|---|---|---|---|
|床|18〜24|5以下|—|20.5 / 3.2で適合|
|背景物（柱・家具・装飾）|床＋5〜12（25〜32）|—|キャラ・敵より弱い（12以下）|柱34.1 / 13.9で超過|
|キャラ・敵・ボス|35以上|15以上|13以上（暫定。8方向版リナは25.2で、揃えるならさらに上げる）|リナ・ヤマアラシ以外は未達。ボスは12.5 / 7.3 / 10.3|

**鉄・煤・黒い体など暗い素材色の敵も、本体の平均明度を床より明らかに上げる。** 発光（目・炉・燠）だけで存在を示さない。鉄は中間調の青灰や茶灰で塗り、左上の明部の帯と縁の明るい線で形を出す（2026-09-26の[格の幅の見本](production/style-reference-2026-09-26/README.md#敵の格の幅の見本-v12026-09-26)で、黒い異形が床に沈むことを確認）。

背景物をキャラ・敵より目立たせない。数値だけでなく、画面をグレースケールにしたとき「床 < 背景物 < キャラ・敵 < 弾」の順に明暗差が読めることを確認する。

### 3.6 弾・VFX

- 明るい芯と、色付きの縁の2層で表現する。煙・火花は大きな形を少数にし、細かい粒子で判定の輪郭を隠さない。
- エフェクトの描き込み密度も[3.1](#31-描き込み密度)に従う。
- 既存の表示倍率・判定の規則は[ステージ素材ガイド](STAGE_ASSET_GUIDE.md)と対象の制作記録に従い、この資料では変更しない。

### 3.7 床と壁

- 現行の旧鋳造区の床は、計測上の明るさ・ばらつき・細部量がこの規格に適合している。作り直しの優先度は低い。
- 床は**大きな石割りと、少数の傷・煤汚れ**を基本とする。石1枚の中に細かい明暗の粒を描かない。
- 石割りの大きさはキャラ全高の約1〜1.5倍を目安とし、キャラより細かい模様にしない。
- 壁・笠石も同じ密度で描き、床より少しだけ描き込みを多くしてよい。家具・柱は壁と同程度。
- 視点・接続・影の分離は[ステージ素材ガイド](STAGE_ASSET_GUIDE.md)と[ステージ制作テンプレート](STAGE_CREATION_TEMPLATE.md)に従う。

## 5. 生成と仕上げの手順

AI生成では、素材ごとに別々に指示すると画風が揺れる。指示文の工夫だけでなく、**基準画像**と**機械的な仕上げ**で揃える。

1. **基準画像（スタイル基準シート）を1枚作る**: リナ・通常敵1体・床・柱/家具1点を通常倍率で並べた見本。以後の生成では参照画像として毎回渡す。作成と採用は別作業。2026-09-26のv1は、現行の敵・環境を参照に渡したため描き方が現行のまま残り、不採用候補（[記録](production/style-reference-2026-09-26/README.md)）。**参照画像はリナだけにし、敵・環境は文章で指示する。** v2（同記録）はこの方法で、全要素がリナと同じ描き方になった。
2. **指示文の共通部分を固定する**: 画風・光源・輪郭・陰影の段数・頭身を述べる共通ブロックを決め、素材固有の指示と分けて記録する。共通ブロックの文面は基準画像と同時に確定する。
3. **生成後の仕上げを全素材で同じ手順にする（未実装・候補）**:
   - 通常倍率の表示サイズを基準にした縮小
   - 系統ごとの共通パレット・色数への減色
   - 輪郭線の付加（動くもの系統のみ）
   - 処理の設定値と入出力を、各素材の派生レシピへ記録する
4. 原本は加工せず保存し、派生物だけを差し替える（既存の原本／派生の分離規則に従う）。

有料生成の実行はユーザーが求めた範囲に限る。この資料の手順は生成許可ではない。

## 6. 確認手順

1. **同倍率の並べ比較**: 同じ床の上で、キャラ・対象素材・既存の基準素材を通常カメラ倍率で並べる。拡大画像で合格判定しない。現行素材の撮影と計測は `tools/capture_style_comparison.gd`（手順は[TESTING](../development/TESTING.md)）。素材を直したら再実行し、3.5の値と比べる。
2. **グレースケール確認**: 色を抜いて「床 < 背景物 < キャラ・敵 < 弾」の明暗順が読めるか。
3. **ぼかし確認**: 軽くぼかした画像で、キャラ・敵の位置と向きが読め、背景の模様が主張しないか。
4. **シルエット確認**: 単色塗りでも種類と向きが分かるか。
5. 自動テスト、目視確認、ユーザー採用を分けて制作記録へ残す。

## 8. 未決事項

- 本規格（基準をキャラ側に置く方向）のユーザー採用。
- 3.5の暫定目標値の採用。細部の最小単位と輪郭の太さは、比較シートでは計測していない。
- 仕上げ処理を既存の画像CLIへ組み込むか、別スクリプトにするか。
- UI（HUD・バッグ）の画風を本規格の対象に含めるか。現状は対象外。
