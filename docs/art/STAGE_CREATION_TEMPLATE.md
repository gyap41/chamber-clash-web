# ステージ制作テンプレート

[素材制作の必読入口](README.md)で共通画風と生成前確認を読み、本書の対象別仕様票へ進む。

ステージの新規作成、素材生成・差し替え、壁・扉・家具配置の変更を始める際に読む共通入口。以下をステージごとの制作資料へコピーして記入する。資料の作成は有料生成の承認を意味しない。

- 美術の共通規格：[STAGE_ASSET_GUIDE](STAGE_ASSET_GUIDE.md)
- ゲーム全体の画風（描き込み密度・輪郭・陰影・色の役割）：[VISUAL_STYLE_GUIDE](VISUAL_STYLE_GUIDE.md)（リナ基準の画風は採用済み。数値の暫定目標は未確定）
- データと描画の実装：[STAGE_TEMPLATES](../development/STAGE_TEMPLATES.md)
- 実行と検証：[TESTING](../development/TESTING.md)
- 生成する場合：[環境設定](../development/ASSET_GENERATION_SETUP.md)と[画像CLI](../../tools/README.md)

## 1. ステージの仕様票

**ステージの動きは素材制作と同じ工程で設計・制作・実装する。** 水・炎・日差しなど、動きが必要な要素を配置計画時に洗い出し、必要な素材分離・マスク・アニメーション・パーティクル・照明を一緒に用意する。静止画の配置だけで完成扱いにしない。対象がない場合は「不要」と理由を記録する。

| 項目 | 記入欄 |
| --- | --- |
| ステージID・名称・用途 | |
| 対象モード・部屋の役割 | 開始／戦闘／宝箱／ショップなど |
| 世界観・基調色・材質 | |
| 基準キャラ・通常表示寸法 | 家具に合わせてキャラを拡縮しない |
| カメラ・部屋の寸法 | 正投影、床範囲、画面内の倍率 |
| 壁の厚み・描画高さ | 衝突形状と描画上の高さを分離 |
| 扉 | ID、四方向、位置、開口幅、到着位置、接続先 |
| 移動・回避・射線 | 通路の余白、大型の敵を置く場合の必要幅 |
| 素材セット／部屋／配置データ | StageTheme／RoomTemplate／FieldDefinition／StagePlacement |
| 既存素材の流用と不足 | 不足の理由を記す |
| 環境の動き | 対象、動かす部分と固定部分、方式、速度・振幅・頻度、必要素材 |
| 動きの接続と確認 | 描画順、光源・粒子の発生位置、停止・再訪、通常倍率・戦闘中の視認性 |

| 完了条件・未対応範囲 | 見た目と動作を別々に記す |

## 2. 必要素材の一覧

各行に「流用／新規／不要」と実ファイル・表示寸法を記入する。全種類の新規生成を必須にしない。

| 部品 | 必要条件・用途 | 方針／ファイル／表示寸法 |
| --- | --- | --- |
| 床 | 反復でき、目地の主張が弱い。人物・敵弾より目立たせない | |
| 壁上面 | 縁なしの地模様。全方向で尺度と材質座標を揃える | |
| 壁正面 | 石目の尺度が一定。両端に柱を焼き込まない | |
| 外周の縁 | 金属などの材質。形状は接続後の外周に沿って描く | |
| 露出した壁端 | 正面と石段の高さを合わせる。正面画像を細く圧縮しない | |
| 扉・敷居 | 開口方向と幅に対応。床との連続性を保つ | |
| 扉の開閉・封鎖 | 通常室はF移動禁止。旧鋳造区v2では石の敷居と封鎖中の鉄の横木（床に置く平らな素材を扉の向きに回転）を表示（2026-09-27）。開閉のアニメーションは未制作 | |
| 室外・基礎 | 暗い室外と控えめな基礎。歩行床と区別 | |
| 低い遮蔽物 | 資材箱・パレット・金床等、部屋の用途に合う形 | |
| 机・作業台 | 強い見下ろし。天板主体、短い正面・脚 | |
| 棚・壁付き設備 | 壁との距離と背面の接地影で取り付きを示す | |
| 炉・排煙設備 | 排煙先が壁または屋根につながる構造 | |
| 壁灯・照明 | 取付面に合う向き。器具・発光位置・影を分離 | |
| 局所装飾 | 煤、擦れ、破片など。用途のある場所に限定 | |

接続用壁材の採用例：[wall-kit-v2](production/wall-kit-v2/README.md)。上面・正面・縁・壁端の4材質を使い、L字・T字等の形状はコードで組み立てる。全接続形状を別々の生成画像にする必要はない。

## 3. 壁の組み立て規則――今回の修正を再発させない

### 上側の角と下側の終端を分ける

| 接続 | 正しい面の割り当て | 避けること |
| --- | --- | --- |
| 北壁と、そこから下へ続く縦壁の角 | 縦壁の上面を北壁の笠石まで連続させる。正面は上面の分だけ切り欠く | 正面優先で上面を途中で切る |
| 通路上壁と、その床際で終わる縦壁 | 縦壁の厚みまで横壁の石積み正面を延ばす。終端の正面と重なる上面だけ除去 | 無地の上面が正面を覆い、柱のように見える |
| L字・T字・十字の上面 | 接続した面の外周だけに縁を描く | 内部境界を横切る縁や二重の角材 |
| 開口の露出端 | 壁の厚みと側面を示す | 継ぎ目隠しの自動柱、金属ブロックの重ね貼り |

画面の上・下だけで決めず、壁が続くか終わるか、隣接する壁の床際が揃うかで判定する。接続後に上面と正面の不要な面積重複がないことを確認する。

- 衝突矩形1個と描画部品1個を必ずしも対応させない。
- 縁付き素材を90度回転して突き合わせない。方向光を焼き込んだ画像も安易に回転しない。
- 模様は壁ごとにリセット・引き伸ばしせず、共通の尺度で描く。
- 壁の外周線は必要。除去対象は内部の不自然な接合線であり、すべての線ではない。
- 装飾柱を使う場合は建築上の意図を持って配置する。
- 廃墟は損壊前の柱軸・壁・通路を先に決め、残る部材と瓦礫をそこから配置する。迂回を見せ場にする場合は、入口間の直進・代替経路の幅・射線を別々に検証する。到達性PASSだけでは、意図した場所を通る構成の確認にはならない。
- 部屋の中に立つ壁（崩れた壁の断片など）は、外周用の壁の仕組みで作らない。壁は常にキャラより下に描くため、後ろに立つとキャラが壁の上に乗って見える。キャラと前後を比べて描く置物にし、足元だけ当たり判定を付ける（2026-09-27、[作り込んだ部屋の試作](production/authored-rooms/README.md)）。
- 壁に重ねる素材（崩れた穴・壁を割る根など）には、周りの石積みを描き込まない。石の大きさ・目地・明るさが本物の壁と合わず、貼ったパッチに見える。生成画像に石積みがある場合は取り除いて使う（`tools/build_wall_feature_cores.gd`）。根が壁から出る表現は、正面が見える北向きの壁だけ。上面しか見えない壁には、壁際の床を割る根を使う（2026-09-27）。
- 角の切り欠き（`cut_corner`）は、北の壁を折り返しの壁の厚みまで残し、張り出した壁は折り返しの壁の隣から始める（2026-09-27修正）。
- 四方向、左右反転、異なる厚さと長さで確認する。任意の斜め壁・高低差は現行方式の対応外。

## 4. 家具・照明・装飾の注意点

- カメラは見下ろしの正投影。低い家具の真上視点と正面写真のような設備を無計画に混在させない。
- テーブルは天板主体。高さを下げるために画像を縮めるだけでなく、長い脚・正面の比率を見直す。
- 炉は大型設備でもよいが、机・道具まで同倍率で大きくしない。キャラを横に置いて判断する。
- 壁灯は壁の正面か側面へ取り付け、上面へ正面用画像を貼らない。
- 歩行用の床占有と射撃用の本体遮蔽を別々に確認する。柱・棚の上部に火球を横切らせ、根元以外を不自然に抜けないか、見えている空間を塞いでいないか確認する。既定の射撃矩形が合わない素材は `projectile_collision` を指定する（2026-10-04）。
- 透過背景、接地位置、描画矩形、衝突矩形、光源位置を個別に記録する。白縁や金具内の背景残りも確認する。
- 家具は足元で人物と前後を切り替える。人物の武器だけが家具の前に出ないこと。
- 煤・擦れは炉や作業台の周囲に限定する。床全体に均一な汚れを追加しない。
- 閉じた端を持つ設備は、端同士を近づけただけで接続設備として扱わない。接続口が一致しない場合は独立設備とし、作業場・通路を含めて配置する。苔や汚れの素材に別の床目地が描き込まれている場合も、下地と一致するか通常倍率で確認する。
- 出入口は建築形状で読めるようにし、大きな円・矢印・縦線で補わない。操作案内は接近時に小さく表示する。

## 5. 素材1点ごとの制作票・プロンプト下書き

### 環境の動きを同時に制作する基準

| 対象がある場合 | 設計する動き | 素材制作時の準備 |
| --- | --- | --- |
| 水面・水桶・冷却槽 | 波、流れる反射、必要に応じて水滴と波紋 | 水域のマスクや別レイヤー。石枠・桶を固定し、小さい水面に合う振幅を決める |
| 焚き火・炉・壁灯 | 炎の揺らぎ、火元ごとの照明変化、必要な火の粉・煙 | 炎と器具の分離、炎色マスクまたはコマ素材、光源・粒子の原点。煙は排煙構造と整合させる |
| 天井の開口・日差し | 光の帯、柔らかい端、光の中の埃 | 光の始点と照射先、減衰マスク、建築との前後関係。空中で突然途切れる帯を避ける |
| 深い開口・遠景 | 必要に応じて薄い靄や落下する塵 | 開口内の表示範囲、遠近に合う速度・濃度、手前の建築との分離 |
| 風が通る場所の紙・布・葉 | 必要に応じて端や先端の揺れ | 固定点、動く部分の分離、風向き。石・太い根など固定構造まで揺らさない |

方式は見せたい動きから選ぶ。連続した歪みや反射にはshader、輪郭が変わる動きにはコマアニメやパーツ、火の粉・煙・埃には少数の粒子、周囲への明るさには照明を使い、必要に応じて組み合わせる。全対象へのパーティクル追加や新規生成を必須にしない。既存素材を使える場合も、同じ制作工程で実装まで接続する。

制作記録には採用方式、必要素材と不足分、マスク・原点・描画順、確認結果を残す。環境の動きは人物・敵弾・攻撃予兆より控えめにし、複数の火元などが一斉に同じ周期で動かないようにする。

```text
素材ID／用途／必要な理由:
流用元または新規生成:
材質・色・基準キャラ:
視点／上面・正面・脚の割合:
原画解像度／ゲーム内表示寸法:
接地基準／透過範囲／衝突矩形:
接続辺・反復周期／隣接する素材:
取付面／排煙等の構造:
描画層／発光・接地影の分離:
動く部分／固定部分／方式（不要なら理由）:
必要なコマ・パーツ・マスク／光源・粒子の原点:
速度・振幅・頻度／停止・再訪時の扱い:
シートの区画・切出し範囲:
禁止事項: 柱や縁の焼き込み、透視収束、床・強い影の焼き込み等
確認場面: 直線、上角、通路終端、L字/T字、キャラの奥・手前・横
保存先／原本／生成条件／派生レシピ:
採用判断／不足／未確認事項:
```

生成前に区画・必要寸法・使用方法を決める。生成画像が指定どおりとは限らないので、石段の数・境界・反復・余白を実物で確認する。原本を保存し、実行用コピーやAtlasTexture、抽出範囲、SHA-256、表示周期をmanifestへ記録する。設定・認証・再送方針は環境ガイドに従う。

## 6. 制作から受入まで

1. 仕様票と素材一覧を埋め、既存素材で仮の床・壁・開口・家具を組む。
2. 四方向の入口、上角と下側の終端、L字/T字、短い壁・長い壁を確認する。
3. 不足分だけ生成または加工し、原本とレシピを保存する。同じ工程で環境の動き・照明・粒子を実装し、配置へ接続する。
4. 通常サイズのキャラを置き、照明あり/なし、奥・手前・横で見た目を確認する。環境の動きは通常倍率で連続再生し、静止画だけで判断しない。
5. 移動・射線・扉への到達・往復・状態保持・描画ノードや光源の重複を検証する。
6. 通常部屋と検証室の画像を保存し、見た目と動作それぞれの結果を記録する。
7. 現行仕様・残課題・実行方法を更新する。詳細な過程は制作記録またはarchiveへ置く。

### 完了チェック

- [ ] 上側の角は上面が連続し、通路終端は正面が連続する。
- [ ] 内部接合線・柱への唐突な切替・石目の縮尺差・白縁がない。
- [ ] 床の反復や照明が人物・敵弾・操作案内を邪魔しない。
- [ ] 家具の高さ、接地、前後関係、取付面、排煙先が自然。
- [ ] 水・炎・光などの動きが必要な対象を洗い出し、素材と同時に制作・実装した。不要・未対応の対象は理由を記録した。
- [ ] 動くレイヤーが静止画像に隠れず、枠・器具など固定部分を歪めない。光の始点・端と粒子の発生位置が自然。
- [ ] 通常倍率の連続再生と戦闘中の視認性、停止・再開、離室・再訪時の破棄や重複、負荷を確認した。未確認項目は明記した。
- [ ] 開口幅と到着位置が有効で、全出入口へ到達できる。
- [ ] 衝突・移動・状態保持と既存モードの回帰を確認した。
- [ ] 素材原本・参照定義・manifest・制作条件・比較画像を保存した。
- [ ] 自動テスト成功、目視確認、ユーザー採用、Web確認を混同せず記録した。

## 7. 今回の採用基準

工房の上角は上面を連続させ、通路終端は正面を連続させる最終修正後、ユーザーから「OK」を得た。以後の比較基準は[工房の採用画面](production/wall-kit-v2/room-preview.png)。この合意は全ステージや任意形状の品質保証ではない。新しい構成はその都度実画面で確認する。

### 床の局所装飾

煤・根・敷物などの平面装飾はfloor_decalで床領域にクリップし、キャラ/家具のYソートから分離する。透過アトラスは要求寸法でなく実出力寸法からセルを決める。石床/壁の素材交換では反復寸法をゲーム内の石の大きさから決め、壁正面と露出端に同じ縦横周期を使う。探索専用テーマ適用時は外部参照フィールドを明示複製し、対戦等の共有元を変更しない。

### 透過余白と接地点の確認

生成PNGの非ゼロalpha領域には、肉眼で見えない半透明の粒が含まれることがある。get_used_rectだけで足元・影・画像寸法を確定しない。見える輪郭（今回の測定はalpha>0.05）と通常表示を照合し、必要な縁の余白を加えた参照領域を素材台帳へ記録する。切り出し後にYソート位置と衝突を再確認する。接地影はshadow_rectで素材の足元へ合わせ、画像高から一律に長い影を出さない。壁へ重ねる根などは別の石積みを焼き込まず、既存建築の材質を見せる。

ランダムマップの部品として作る場合は、部屋の役割・許可する開口の組合せ・入口ごとの到達性・主経路と任意の寄り道を記録する。見学用の並び順に依存させず、非対応の開口を抽選しない。美術上の閉鎖門と接続可能な出口を区別する。

### 地底・遠景を覗く開口

床上に背景画像を置くだけにしない。開口の側面・床断面・手前の縁を建築へ接続し、画像の端を構造で覆う。強い見下ろしの部屋には下層の上面が見える景色を使い、水平線のある横向きパノラマと混在させない。画像内の非歩行領域と衝突、欄干の継ぎ目、手前の横断通路を別々に確認する。
