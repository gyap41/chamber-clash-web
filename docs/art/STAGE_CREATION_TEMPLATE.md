# ステージ制作テンプレート

ステージの新規作成、素材生成・差し替え、壁・扉・家具配置の変更を始める際に読む共通入口。以下をステージごとの制作資料へコピーして記入する。資料の作成は有料生成の承認を意味しない。

- 美術の共通規格：[STAGE_ASSET_GUIDE](STAGE_ASSET_GUIDE.md)
- データと描画の実装：[STAGE_TEMPLATES](../development/STAGE_TEMPLATES.md)
- 実行と検証：[TESTING](../development/TESTING.md)
- 生成する場合：[環境設定](../development/ASSET_GENERATION_SETUP.md)と[画像CLI](../../tools/README.md)

## 2. 必要素材の一覧

各行に「流用／新規／不要」と実ファイル・表示寸法を記入する。全種類の新規生成を必須にしない。

| 部品 | 必要条件・用途 | 方針／ファイル／表示寸法 |
| --- | --- | --- |
| 床 | 反復でき、目地の主張が弱い。人物・敵弾より目立たせない | |
| 壁上面 | 縁なしの地模様。全方向で尺度と材質座標を揃える | |
| 壁正面 | 石目の尺度が一定。両端に柱を焼き込まない | |
| 外周の縁 | 金属などの材質。形状は接続後の外周に沿って描く | |
| 露出した壁端 | 正面と石段の高さを合わせる。正面画像を細く圧縮しない | |
| 扉・敷居 | 開口方向と幅に対応。床との連続性を保つ | |
| 扉の開閉・封鎖 | 通常室はF移動禁止と横棒の仮表示。正式な開閉・封鎖素材は別途必要 | |
| 室外・基礎 | 暗い室外と控えめな基礎。歩行床と区別 | |
| 低い遮蔽物 | 資材箱・パレット・金床等、部屋の用途に合う形 | |
| 机・作業台 | 強い見下ろし。天板主体、短い正面・脚 | |
| 棚・壁付き設備 | 壁との距離と背面の接地影で取り付きを示す | |
| 炉・排煙設備 | 排煙先が壁または屋根につながる構造 | |
| 壁灯・照明 | 取付面に合う向き。器具・発光位置・影を分離 | |
| 局所装飾 | 煤、擦れ、破片など。用途のある場所に限定 | |
| 拾得物・操作設備 | 識別と操作に必要なものだけ追加 | |

接続用壁材の採用例：[wall-kit-v2](production/wall-kit-v2/README.md)。上面・正面・縁・壁端の4材質を使い、L字・T字等の形状はコードで組み立てる。全接続形状を別々の生成画像にする必要はない。

## 3. 壁の組み立て規則――今回の修正を再発させない

### 上側の角と下側の終端を分ける

| 接続 | 正しい面の割り当て | 避けること |
| --- | --- | --- |
| 北壁と、そこから下へ続く縦壁の角 | 縦壁の上面を北壁の笠石まで連続させる。正面は上面の分だけ切り欠く | 正面優先で上面を途中で切る |
| 通路上壁と、その床際で終わる縦壁 | 縦壁の厚みまで横壁の石積み正面を延ばす。終端の正面と重なる上面だけ除去 | 無地の上面が正面を覆い、柱のように見える |
| L字・T字・十字の上面 | 接続した面の外周だけに縁を描く | 内部境界を横切る縁や二重の角材 |
| 開口の露出端 | 壁の厚みと側面を示す | 継ぎ目隠しの自動柱、金属ブロックの重ね貼り |

画面の上・下だけで決めず、壁が続くか終わるか、隣接する壁の床際が揃うかで判定する。接続後に上面と正面の不要な面積重複がないことを確認する。

- 衝突矩形1個と描画部品1個を必ずしも対応させない。
- 縁付き素材を90度回転して突き合わせない。方向光を焼き込んだ画像も安易に回転しない。
- 模様は壁ごとにリセット・引き伸ばしせず、共通の尺度で描く。
- 壁の外周線は必要。除去対象は内部の不自然な接合線であり、すべての線ではない。
- 装飾柱を使う場合は建築上の意図を持って配置する。
- 四方向、左右反転、異なる厚さと長さで確認する。任意の斜め壁・高低差は現行方式の対応外。

## 4. 家具・照明・装飾の注意点

- カメラは見下ろしの正投影。低い家具の真上視点と正面写真のような設備を無計画に混在させない。
- テーブルは天板主体。高さを下げるために画像を縮めるだけでなく、長い脚・正面の比率を見直す。
- 炉は大型設備でもよいが、机・道具まで同倍率で大きくしない。キャラを横に置いて判断する。
- 壁灯は壁の正面か側面へ取り付け、上面へ正面用画像を貼らない。
- 透過背景、接地位置、描画矩形、衝突矩形、光源位置を個別に記録する。白縁や金具内の背景残りも確認する。
- 家具は足元で人物と前後を切り替える。人物の武器だけが家具の前に出ないこと。
- 煤・擦れは炉や作業台の周囲に限定する。床全体に均一な汚れを追加しない。
- 出入口は建築形状で読めるようにし、大きな円・矢印・縦線で補わない。操作案内は接近時に小さく表示する。

## 5. 素材1点ごとの制作票・プロンプト下書き

```text
素材ID／用途／必要な理由:
流用元または新規生成:
材質・色・基準キャラ:
視点／上面・正面・脚の割合:
原画解像度／ゲーム内表示寸法:
接地基準／透過範囲／衝突矩形:
接続辺・反復周期／隣接する素材:
取付面／排煙等の構造:
描画層／発光・接地影の分離:
シートの区画・切出し範囲:
禁止事項: 柱や縁の焼き込み、透視収束、床・強い影の焼き込み等
確認場面: 直線、上角、通路終端、L字/T字、キャラの奥・手前・横
保存先／原本／生成条件／派生レシピ:
採用判断／不足／未確認事項:
```

生成前に区画・必要寸法・使用方法を決める。生成画像が指定どおりとは限らないので、石段の数・境界・反復・余白を実物で確認する。原本を保存し、実行用コピーやAtlasTexture、抽出範囲、SHA-256、表示周期をmanifestへ記録する。設定・認証・再送方針は環境ガイドに従う。

## 6. 制作から受入まで

1. 仕様票と素材一覧を埋め、既存素材で仮の床・壁・開口・家具を組む。
2. 四方向の入口、上角と下側の終端、L字/T字、短い壁・長い壁を確認する。
3. 不足分だけ生成または加工し、原本とレシピを保存する。
4. 通常サイズのキャラを置き、照明あり/なし、奥・手前・横で見た目を確認する。
5. 移動・射線・扉への到達・往復・状態保持・描画ノードや光源の重複を検証する。
6. 通常部屋と検証室の画像を保存し、見た目と動作それぞれの結果を記録する。
7. 現行仕様・残課題・実行方法を更新する。詳細な過程は制作記録またはarchiveへ置く。

### 完了チェック

- [ ] 上側の角は上面が連続し、通路終端は正面が連続する。
- [ ] 内部接合線・柱への唐突な切替・石目の縮尺差・白縁がない。
- [ ] 床の反復や照明が人物・敵弾・操作案内を邪魔しない。
- [ ] 家具の高さ、接地、前後関係、取付面、排煙先が自然。
- [ ] 開口幅と到着位置が有効で、全出入口へ到達できる。
- [ ] 衝突・移動・状態保持と既存モードの回帰を確認した。
- [ ] 素材原本・参照定義・manifest・制作条件・比較画像を保存した。
- [ ] 自動テスト成功、目視確認、ユーザー採用、Web確認を混同せず記録した。

関連テスト：connected_wall_surface、wall_junctions、four_way_rooms、exploration_rooms、stage_depth、stage_templates、field_layout。変更内容に応じて選び、具体的なコマンドと既知の終了時警告はTESTINGを参照する。

## 7. 今回の採用基準

工房の上角は上面を連続させ、通路終端は正面を連続させる最終修正後、ユーザーから「OK」を得た。以後の比較基準は[工房の採用画面](production/wall-kit-v2/room-preview.png)。この合意は全ステージや任意形状の品質保証ではない。新しい構成はその都度実画面で確認する。
