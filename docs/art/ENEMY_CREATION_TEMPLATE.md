# 敵素材の制作テンプレート

区分: 共通制作手順。敵・ボスの素材生成やアニメーション制作を始める前に使用する。必要素材の整理と、生成・実装・受入を分ける。資料作成だけでは有料生成しない。

関連: [敵・ボスの計画](../planning/ENEMY_BOSS_ART_PLAN.md)、[現行ルール](../design/GAME_RULES.md)、[表示の構成](../development/ACTOR_ANIMATION.md)、[音響基準](../AUDIO_BIBLE.md)、[生成環境](../development/ASSET_GENERATION_SETUP.md)。

ボスでは[ボス制作テンプレート](BOSS_CREATION_TEMPLATE.md)も使用する。攻撃選択、演出の進行、報酬、音響の同期を含む追加チェックを行う。

## 1. 制作前に決める仕様票

敵ごとの制作記録（art/production）へ以下を記入する。未確定項目は未確定と書き、完成画像だけ先に大量生成しない。

|項目|記入内容|
|---|---|
|敵ID・役割・状態|名称、機械／生物、近接／射撃等、提案／実装済み|
|参照元|敵定義・攻撃処理・既存画像・採用設定のパス|
|画風・視点|既存プレイヤーと同じ見下ろし、光源、輪郭、材質|
|寸法|通常倍率の胴・足・武器・尾を含む最大表示範囲、原画解像度、縮小倍率|
|判定との関係|接地中心、移動／被弾半径、攻撃範囲。画像の外接寸法とは別に記録|
|方向|前・後・右・左、必要なら斜め。非対称装備は反転不可として専用方向を用意|
|動作方式|関節パーツ／歩行コマ／併用、採用理由。全身の拡縮だけで足運びを代用しない|
|動作一覧|待機、移動、構え、各攻撃、復帰、被弾、撃破。ない動作は理由を記載|
|戦闘との同期|予備動作・発射・命中・硬直の既存時刻、方向固定、キャンセル条件|
|必要数と生成範囲|不足素材ID、方向数、コマ数、パーツ数、今回制作する範囲|

## 2. 必要素材の台帳

必要な画像・VFX・SEを一つの一覧で管理し、既存素材の有無を先に調べる。

|素材ID|用途／動作|方向|パーツまたはコマ数|原点／接続点|既存・流用・新規|状態／不足|確認方法|
|---|---|---|---|---|---|---|---|
|例: enemy_walk_front|前向き歩行|前|案: 6コマ|共通接地原点|新規|未制作|通常倍率で最低3周|

状態は「未制作」「生成済み」「切出し・補筆済み」「組立済み」「本編接続済み」「目視／試聴済み」「ユーザー採用」を区別する。原本パス、生成指示、ハッシュ、派生レシピ、実装参照先を記録。1枚のシートを生成しただけで全動作が揃った扱いにしない。

## 3. 関節パーツ方式で必要なもの

- 胴、必要なら頭、左右の上腕・前腕・手、武器、左右の腿・すね・足。尾・顎・喉袋は動かす必要に応じて独立させる。
- パーツごとの親、ピボット、接続先、初期位置、可動角度、方向別の描画順。武器の握り位置と発射口も記録する。
- 関節の重なり部分と、腕・脚の後ろに隠れる胴を描き足す。切断面や透明な穴が最大可動角で見えないこと。
- 前後方向で見える面が変わる腕・足・武器には差し替え絵を用意。横向きのパーツを回転するだけで上下への攻撃を作らない。
- 足が床に残る接地期間と持ち上げる期間を決め、歩幅を実移動距離に対応させる。壁に押し付けた状態と停止・再開を試す。

## 4. コマ方式で必要なもの

- 各方向の歩行1周期。通常敵はまず4〜6コマを案として、接地・踏み出し・通過・反対脚の接地が読めるかで必要数を決める。枚数そのものを完成条件にしない。
- 全コマで共通キャンバス、接地原点、胴寸法、色、光源、装備側を維持。各コマの余白へ合わせた自動拡大縮小は禁止。
- 四足の場合は接地する脚の組み合わせ、胴の上下動、尾の遅れを決める。別パーツの喉袋・顎などを重ねるなら、胴側に同じ部位を重複して焼き込まない。
- 待機→歩行→停止、構え→発射／打撃→復帰のつなぎを用意。最初と最後が飛ぶ歩行ループを避ける。

## 5. 動作・演出・音響の対応表

|動作|必要な絵・動き|音やエフェクトの扱い|
|---|---|---|
|待機|呼吸、重心、装備の小さな揺れ|常時SEは必要な場合だけ|
|移動|左右／四足の接地、胴・尾の追従|足音は必要性と同時発音数を先に判断|
|構え|沈み込み、武器持上げ、吸気・喉袋膨張|警告音ではなく動作音を基本にする|
|攻撃|狙う方向に一致する武器や口、反動|発射／空振り／実際の命中を区別。弾・閃光・影は別素材|
|復帰|武器の戻し、息継ぎ、姿勢の回復|連射や硬直時間と整合する尾の長さ|
|被弾|短い揺れや色変化、必要なら差分|見た目のひるみだけで攻撃を中断しない|
|撃破|停止→崩れる／倒れる→消失または残骸|機械と生物の材質を分ける。死亡判定・退役は即時。報酬の見せ方は別管理とし、ボス箱は撃破演出後の出現も可|

音は[AUDIO_BIBLE](../AUDIO_BIBLE.md)とmanifestを確認し、既存流用を評価して不足だけ生成。プロンプトの意図と実際に聞こえる音を混同しない。

## 6. 制作順と完了条件

1. 台帳を埋め、現行素材で足りないものを具体化する。
2. 1方向の簡易パーツ／少数コマで歩行と攻撃を組み、寸法・歩幅・ピボットを確認する。
3. その仕様で方向・動作を展開。生成物の同一性、関節の隠れた面、透過縁を確認する。
4. 本編へ接続。戦闘側の時刻を表示へ渡し、画像の再生終了から攻撃判定を決めない。
5. 通常サイズの動画または連続フレームで、全方向の歩行ループ・停止・再開・構え・攻撃・撃破を確認する。静止画だけで「自然に歩く」と判定しない。
6. 壁際、家具の前後、明暗の床、複数敵・弾、画面端、ポーズ・再開、再訪・リセットを確認。Web／低性能端末の負荷は別に記録。

原本・加工手順・実装先・通常倍率の確認資料・未確認事項を保存する。自動テスト、連続動作の目視、SE試聴、ユーザー採用はそれぞれ報告する。未完了の動作があれば明記し、「グラフィック反映済み」を「全アニメーション完成」の意味で使わない。

## 7. 敵・ボス共通の品質基準

目的は、種族や制作方式が違っても動きの完成度・情報の読みやすさ・音の整合をそろえること。全員のコマ数、音量、派手さを同じにすることではない。通常敵にも以下の全項目を適用し、ボスは固有攻撃・段階移行・開始／撃破の演出を追加する。これは制作時の合否基準であり、既存素材がすべて合格済みという意味ではない。

### 共通の合格条件

|観点|合格条件|要修正の例|
|---|---|---|
|画風・縮尺|同じ床・カメラ倍率で、輪郭、光源、見下ろし角、材質の描き込み密度が基準と調和。意図した体格差を記録|ある敵だけ輪郭がぼける、正面絵になる、コマ間で胴寸法が変わる|
|移動・接地|移動方式に合う重心と支持が読め、発進・停止・旋回・壁押しがつながる|歩行脚が滑り続ける、停止中も前進用の足運びを続ける、旋回で原点が跳ぶ|
|攻撃動作|構え→力の放出→反動／戻しが通常速度で識別でき、攻撃部位と方向が一致|弾だけ出る、着地前に衝撃波が出る、復帰姿勢へ突然戻る|
|方向・つなぎ|必要な全方向で接続点・装備側・前後関係が維持され、状態境界とループが飛ばない|隣コマ混入、関節の穴、回転で武器が別の側へ移る|
|被弾・撃破|通常動作との差が読み取れ、死亡と継続攻撃を誤認しない。消失・残骸まで完結|被弾で意図せず攻撃が解除、死後に発射、消失途中の残像が残る|
|VFXの情報整理|攻撃本体・敵弾・プレイヤー・回避可能な床を識別でき、床との高さが整合|煙や光が判定や逃げ道を隠す、弱攻撃が大技より常に目立つ|
|音の材質・役割|動作／材質に合い、構え・発射・命中・撃破を用途どおり区別できる|炎が金属音に聞こえる、空振りなのに命中音、軽い攻撃だけ極端に大きい|
|音の同期・混雑|聞こえるアタックが動作に合い、最大想定編成でも重要音を聞き取れる|無音の頭で発射後に鳴る、同時音で割れる、BGMで被弾音が埋まる|

歩行しない浮遊・滑走・車輪移動には足運びを強制しない。代わりに浮力、慣性、車輪回転等、その方式の支持と移動が読めることを確認する。通常敵へボス並みの長い構え・撃破や専用SE一式を強制しない。省略は役割上の理由を記録し、同等の読みやすさを確保する。

### 比較用の基準と確認条件

制作前に、比較用の既存敵・動作・SEを具体的なファイルと実装版で指定する。「既存と同じ」「リッチに」だけでは基準にしない。基準は項目ごとに選んでよいが、目視・試聴またはユーザー評価で採用された範囲を明記する。基準自体が未確認なら暫定と記し、合格済みの見本として扱わない。現行の鋳造機や通常敵にも未試聴等が残っており、一括で完成基準にはしない。

- 同じ通常カメラ倍率・解像度・明暗の床で、プレイヤーと基準敵を並べて比較する。拡大表示は不具合調査用で、通常サイズの評価を代替しない。
- 全方向の待機・移動を最低3周期、発進→停止→旋回、各攻撃→復帰を最低3回確認。通常速度の連続映像を必須とし、必要箇所だけコマ送りを併用する。
- 単体と最大想定編成の2条件を用意し、弾・VFX・SEの混雑を確認する。ボスは通常／強化段階の両方を含める。
- 同期はイベントの発火ログだけでなく、表示された発射／接触フレームと実際に聞こえる音の立ち上がりを録画で比較する。意図したずれは理由と許容範囲を制作票に記録する。
- 音の比較条件と合否は[AUDIO_BIBLEの共通品質レビュー](../AUDIO_BIBLE.md#敵ボスの共通品質レビュー)に従う。

### 品質レビュー票（各制作記録へ複製）

|項目・対象動作|基準素材と採用範囲|確認環境・実装版|証拠の映像／録音と時刻|判定|不具合・次の修正|
|---|---|---|---|---|---|
|例: 移動・右向き|対象とパスを記入|倍率・fps・床・編成|通常速度3周期|未確認|記入|

判定は「未確認／要修正／合格／対象外（理由必須）」とする。「見た・聞いた」は確認行為であり、合格ではない。必須項目が未確認または要修正なら品質レビュー完了とはしない。進行停止、攻撃方向や同期の誤認、音割れ・重要音の消失は他項目の良さで相殺しない。ユーザー採用はこの判定と別欄に記録する。

この基準の変更時は、影響する既存敵の再レビュー対象と未確認項目をROADMAPへ記す。資料を更新しただけで既存敵を合格へ変更しない。
