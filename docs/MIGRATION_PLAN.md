## 方針
- Godot 4.5.1 / GDScript / Compatibility。固定物理更新で戦闘を処理。
- WebとWindowsの両方へ出力する。まずCPU対戦・ローカル2人対戦を移植し、オンライン対戦は別計画。
- 元の数値・素材・仕様を移植基準にする。ゲーム性の大幅変更は移植後。
- プロジェクトZIPを開き、project.godotをインポートしてF6/F5で実行する。

## M1の意図的な仮実装
プレイヤーは円の仮表示。左右の自動照準、同一HP8・速度205。通常弾と跳弾は検証用で、8発/予備40発を共有。E/Oで切替。正式な4枠インベントリではない。アリーナは3障害物の検証用。音声・ショップ・CPU・縮小・パルスは未実装。全素材とcatalog.jsonは保存済みだが、保存だけでゲーム処理の移植完了とはしない。

## 以後の構成
M3前にmain.gdの検証用処理をPlayer、Projectile、RoundManagerへ分離。装備定義はResource等へ変換し、在庫の残弾など可変状態と共有定義を分ける。UIはControlとThemeで再構築。既存PNGは切り出し座標と原点を調整。キャラ歩行は現在の簡易動作と本格素材追加を分ける。

## バランス基準
ショップ100CR、負け点差ごと15CR追加（最大30）、2点まで。品揃え共通・在庫別。ラウンドごと資金/装備リセット。武器4枠・レリック3枠。近接120度/64px/弾消し最大3/CT1.1秒/射撃硬直0.3秒/ダメージ0.6。移植後に値変更する場合は変更履歴へ明記。

## 主なリスクと確認
- 高速弾:細分化移動またはスイープ判定。薄い壁を通過しない。
- 回避/壁際:四隅から脱出可能。壁抜け・スタックなし。
- 素材:コマ原点ずれ、弾の視覚中心と判定を比較。
- Web:書き出しテンプレート、配信設定、音声開始、読み込み時間を実機確認。
- SE:Web AudioのJS処理を直接転用せず、WAV化または再制作。
- 移行完了判断:全機能チェックと対人プレイ確認後。現行版を削除せず戻せる状態を保持。
