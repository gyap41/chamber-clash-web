# 探索報酬・宝箱・発見の演出案

更新: 2026-09-22。P4初期試作として初戦クリア保証箱を実装。現行動作は[GAME_RULES](../design/GAME_RULES.md)を参照。以下の通常箱確率・宝箱部屋・補給・店は引き続き提案／未実装。[工程](EXPLORATION_ROADMAP.md)。

## 期待と緊張の波

「扉の先の痕跡→未知の戦い→一息→報酬→装備の選択→次の分岐」を基本にする。常に戦闘、常に箱、常に豪華演出にはしない。宝箱のために寄り道する意味と、強敵に挑むかの選択を作る。

| 場所 | 報酬の提案 | 発見の手掛かり |
| --- | --- | --- |
| 通常戦 | 小さな資源報酬。ときどき攻略後に宝箱が出現 | 戦闘後に部屋の中央付近で短い出現演出 |
| 宝箱部屋 | 装備を得る保証枠。初期は鍵なし | 扉の紋様、温かな光、置かれた収納箱 |
| 任意の強敵部屋 | 危険と報酬の種類を入室前に示し、攻略で良い箱を保証 | 傷の多い扉、巣、警戒灯。マップにも訪問後表示 |
| ショップ | 買物・不足補給。経済は探索専用 | 人の生活感・看板。通常戦と音の密度を変える |
| ボス前室 | 整理と相手のヒント。無料全回復は前提にしない | 殻、足跡、床の焦げ、遠くの音 |
| ボス撃破 | 今回の挑戦を伸ばす報酬を保証。出口と別に識別 | 静けさ→撃破余韻→箱/報酬→次階層の出口 |

通常戦箱は初期検証値として25〜35%を候補にするが未採用。連続不出現を抑える保証カウンタを比較し、無料の箱が多すぎて宝箱部屋の価値が薄れないかを見る。宝箱部屋と最低補給は通常箱抽選と独立させる。ノーダメージは小さな追加報酬候補とし、苦戦した人から基礎報酬まで奪わない。

装備箱は「武器」「レリック」「いずれか」など内容カテゴリを箱の意匠でも伝える。高レアは色だけでなく留め具・形・音で識別。初期案は1点提示、選択箱は後続候補。鍵・ミミック・呪い箱・隠し部屋は基礎体験の後に検討する。

## 宝箱の状態と一度だけの取得

提案する論理状態：未出現→出現済み/閉→開封済み/内容未取得→取得済み/空。見た目の出現中・開封中は表示状態として別管理する。

1. 部屋攻略時に報酬IDと内容を一度だけ確定。相打ち死亡時は新しい報酬を確定しない。
2. 移動可能な場所に箱を置く。扉・到着点・家具の裏を避け、置けなければ検証済みの代替位置を使う。箱で出口を塞がない。
3. Fで開封。連打で多重開封しない。近くの扉と箱が重なる場合は操作対象を明示する。
4. 容量不足なら「開いているが中身が残る」状態にする。バッグ整理後に再取得でき、勝手に消えない。
5. 所持品への付与と取得済み記録を一括で確定。無料品の売却額・弾薬は既存の取得元ルールを確認し、再拾得で利益を増殖させない。
6. 再訪で閉じた箱へ戻さず、中身も再抽選しない。将来の保存はrun_id・部屋ID・報酬ID・内容/個体ID・取得状態を持つ。アニメーション再生位置の保存は不要。

報酬用乱数は部屋生成/装飾/AIから分離。中身と不出現カウンタを保存し、ロード回数や歩数で抽選結果を変えない。戦闘中セーブの完全復元はP5の初期対象外。

## アニメーションとSE

時間は仮の目安。操作を長く奪わず、通常箱は繰り返し開けても煩わしくない長さにする。

| 契機 | 見た目の案 | 音の役割 | 発火条件 |
| --- | --- | --- | --- |
| 攻略 | 最後の敵が倒れ、扉の封鎖が解ける | 短い解放音 | 攻略状態確定に1回 |
| 箱出現 | 約0.4秒の光/埃、箱が軽く落ち着く | 小さな着地音＋発見音 | 出現成功に1回。再訪では鳴らさない |
| 待機 | 留め具や隙間の控えめな光 | 常時SEは原則なし | 複数箱で音が重ならない |
| 開封 | 約0.3〜0.5秒、留め具が外れ、蓋が開く | 留め具→蓋の材質音 | 開封受理された1回だけ |
| 内容提示 | 約0.2〜0.4秒、中身が浮かび上がる | レア度に応じた短い音 | 内容を初めて提示した1回 |
| 取得 | 中身が手元へ吸い寄せられ、名前を短く表示 | 既存pickup等の適合を確認 | 所持品への付与成功時のみ |
| 満杯 | 中身を残し、整理の案内 | 小さな拒否音または無音 | 押しっぱなしで連続発火させない |

蓋・箱本体・留め具・内部・光・影を分け、開いた蓋の下に中身が隠れないようにする。木箱と生物由来の繭箱は同じ論理状態を使えても、音と開く動作を別にする。最初は既存の箱を仮使用し、正式な箱1種で工程を確認してから種類を増やす。

開封中にマップ・バッグ・フォーカス停止が入った場合は表示も停止する。離室・ロード後は論理状態から静止状態へ復元し、SEや取得を再発火させない。箱を開けるボタン操作が射撃へ漏れないこと。音の接続は状態遷移に対応するイベントIDで一度だけ行い、描画フレームごとに鳴らさない。

## 素材と検証

必要候補：箱の閉/開と蓋の可動素材、接地影、出現粒子、内容提示台座、開封/出現/取得/希少通知SE。既存素材と [audio manifest](../../assets/audio/asset_manifest.json) を制作時に照合し、同じ用途の音を重複生成しない。[音響基準](../AUDIO_BIBLE.md)、[生成環境](../development/ASSET_GENERATION_SETUP.md)、[統一CLI](../../tools/asset_generator/README.md)が作業入口。今回は生成しない。

実装時の確認：連打・満杯・再訪・同時死亡・離室・停止復帰で二重取得なし。音なしでレア度と取得可否が分かる。箱出現位置へ到達できる。低レアでも成長や不足補給に意味があり、通常戦で毎回整理を強いない。再挑戦ごとに報酬内容と経路の選択が変わる。手動での期待感・音量/気持ちよさは自動テスト成功とは別に評価する。
