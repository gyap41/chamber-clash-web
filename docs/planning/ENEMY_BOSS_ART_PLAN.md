# 敵・ボスの見た目とパーツ制作案

更新: 2026-09-22。通常敵の現状と今後の制作案を区別して記載。ボス仕様は未実装の案であり、生成依頼・予算承認ではない。制作開始時は[敵素材の制作テンプレート](../art/ENEMY_CREATION_TEMPLATE.md)で必要素材を整理する。[体験と敵案](EXPLORATION_DESIGN.md)、[既存アニメーションの責務](../development/ACTOR_ANIMATION.md)、[素材ガイド](../art/STAGE_ASSET_GUIDE.md)を参照。

ボスの実制作・実装・レビューでは[ボス制作テンプレート](../art/BOSS_CREATION_TEMPLATE.md)を併読し、古い案を現在の採用仕様と混同しない。

## 通常敵の現状

[アニメーションv2](../art/production/enemy-animation-v2/README.md)を本編へ組み込み済み。両種とも4方向×歩行4コマ・構え・攻撃・復帰・倒れを用意。番機も関節分割案から専用コマ方式へ変更した。被弾反応と独立した撃破表示を接続し、表示を約20%拡大、判定は維持。歩行の距離同期・停止・退役後の撃破表示を自動確認。全方向の連続動作の自然さ、実機負荷、ユーザー採用が残る。

独立関節リグは未実装だが、現在の通常敵の必須方式とはしない。ボスなど可動域の大きな敵では以下の分割案を個別に検討する。

## 大きさと見下ろし

既存プレイヤーの通常描画を基準にする。カメラ倍率1、1120×600の遊べる表示範囲で比較し、ボスを大きくするためにプレイヤーを縮めない。設定画の解像度と表示寸法と当たり判定を別々に記録する。

| 対象 | 表示外接寸法の試作案 | 移動判定の試作案 | 確認点 |
| --- | --- | --- | --- |
| 通常敵 | 約32〜64px | 半径14〜20px | 小さくても頭・口・攻撃方向が読める |
| 管理機 | 幅150〜180、高さ160〜200px。腕を広げた最大幅240px程度 | 胴の足元半径40〜48px | 腕の伸びを移動判定に入れない。炉口が銃弾で隠れない |
| 鉱殻の巣主 | 幅180〜220、奥行き140〜180px | 半径45〜55px | 背中の大きさと足元の判定に納得できる |
| 菌冠の母体 | 幅180〜240、高さ160〜200px | 根元半径40〜55px | 傘がプレイヤー・弾を長時間隠さない |

いずれも仮値。半径14pxだけを対象にした現行到達性チェックでは大型ボスを保証できない。大型半径の移動・旋回・壁際の退避、プレイヤーの回避経路を個別検証する。入口を通れない大型ボスは室内配置とし、通路へ追従させない。絵の外接矩形全体を被弾・接触判定に流用しない。

## パーツ分割

**機械は関節で分割、生物は塊の変形と差し替え絵を併用する。** 全身1枚の拡縮だけ、または細切れの回転だけで全動作を作らない。

| ボス | 独立パーツの初期案 | 差し替えが必要な絵 |
| --- | --- | --- |
| 管理機 | 胴、頭、炉口蓋、炉内発光、左右上腕/前腕、工具、左右足、背面配管、影 | 腕の前後向き、工具を振り上げた上面、潰れた着地、破損した外装 |
| 巣主 | 胸腹部、背甲、頭/顎、左右前脚、後脚の組、尾、影 | 腹の圧縮/伸張、顎の開閉、脚の踏ん張り、背甲の開き、突進姿勢 |
| 母体 | 根元、幹、傘、前後の触根、複数胞子嚢、発光、影 | 傘の開閉と内側、嚢の膨張、根の打撃先端 |

分割数は目安として10〜18程度から始め、見えない細部まで増やさない。左右非対称の工具や欠けた甲殻は単純反転しない。前・後・側面の最低3方向をラフで試し、攻撃に必要な斜め方向だけ追加する。方向の光・足元・パーツ順序を揃え、背中素材を正面の回転で代用しない。

各パーツは透明背景、共通キャンバスと座標系、足元原点、接続ピボットを記録。重なる関節の内側まで描き、回転時の隙間を防ぐ。強い落ち影・発光・煙を身体へ焼き込まず別層にする。AIが生成したパーツシートをそのまま分離可能とは仮定せず、接続部分の補筆・切出し・方向整合を確認する。

## 動作とゲーム判定

| 状態 | 管理機 | 巣主 |
| --- | --- | --- |
| 待機 | 炉の明滅、重心、腕の微振動 | 呼吸、触角、足の小さな動き |
| 移動 | 左右の接地と胴の重み | 脚の交互接地、腹の追従 |
| 予備動作 | 工具の持上げ・炉口の開き | 身を沈める・前脚を開く |
| 攻撃 | 重い振下ろし・発射反動 | 突進・横払い・鉱片の放出 |
| 硬直 | 工具が抜けない・放熱 | 滑って停止・息継ぎ |
| 被弾 | 外装の短い振動 | 表面の小さな収縮 |
| 段階移行 | 排熱蓋が開く | 背甲の一部が剥がれる |
| 撃破 | 動力停止→崩れる→静止 | 脚が折り畳まれる→倒れる→静止 |

戦闘タイマーと攻撃確定が正本。AnimationPlayer/AnimationTreeは表示を追従させ、アニメーション終了通知だけでダメージ・報酬を確定しない。高頻度の被弾で攻撃が常にキャンセルされないよう、被弾表示は主動作と分離する。実際に中断可能な技は敵定義で明示する。

実装案はActor本体（HP・移動・AI）→表示スナップショット→BossVisual（パーツ・クリップ）。既存8キャラ専用のグラフへ全ボスの分岐を追加しない。部位破壊がルールとして必要になるまでは、見た目の破損と独立部位HPを混同しない。前後関係は足元Yと方向別のパーツ順序で扱い、武器だけが家具の前に出る問題も再確認する。

## 制作の段階と受入

1. シルエット案と通常サイズ比較。プレイヤーと弾を一緒に置く。
2. 無地パーツでピボット・前後・移動・攻撃1つを試す。
3. 戦闘範囲と寸法を固定して、1体の原画・必要方向・差分を制作。
4. 組み立て、予備動作→攻撃→隙、被弾と死亡を接続。
5. 全方向・壁際・画面端・暗い床・明るい床・複数エフェクト下を通常サイズで確認。
6. 1体目で工程を確認してから、生物ボスと別の組み合わせへ展開する。

素材ごとの記録：ID／生態と役割／表示寸法／移動・被弾・攻撃判定／原画寸法／方向／パーツIDとピボット／最大可動域／描画順／差し替えフレーム／予備動作と当たり時間／原本と派生レシピ／動作映像／未確認事項。

音響は唸り・足音・工具・殻の擦れなど材質に合わせる。全ボスで同じ機械音を使わない。既存素材の確認と生成手順は[AUDIO_BIBLE](../AUDIO_BIBLE.md)と[環境ガイド](../development/ASSET_GENERATION_SETUP.md)へ集約する。今回は画像・SE・BGMを生成しない。
