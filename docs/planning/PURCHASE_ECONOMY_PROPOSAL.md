# 購入制・バッグ投資・試合尺の検討案

更新: 2026-09-11。ユーザーとの仕様検討用。以下は提案であり、未承認・未実装・実プレイ未検証。
現行仕様は GAME_RULES.md の無料報酬・3本先取。今回ゲームコードは変更していない。

## 目的と試合の長さ

無料アイテム選択を資金配分へ置き換え、武器・重複レリック・改造・バッグ拡張を競合する投資にする。
キャラ初期武器とフィールド取得は無料。試合をまたぐ能力・資金の持ち越しはしない。

|勝利条件|決着ラウンド数（引き分け除外）|判断|
|---|---|---|
|3本先取|3〜5|短時間向き。最短では成長のための準備が初回以外に2回しかない|
|4本先取|4〜7|長さが問題になった場合の比較案|
|5本先取|5〜9|推奨試作。序盤投資・中盤構築・完成後の戦闘を検証する|

まず5本先取とし、戦闘上限90秒は維持する。準備は当初時間制限なし。
完成を第4〜5戦までに経験できるよう調整し、第9戦まで進むことを前提に価格を設計しない。
目標の総所要時間は12〜18分だが実測値ではない。90秒を使い切り、各準備を45秒と仮定すると
5〜9戦は11分15秒〜20分15秒（結果画面・引き分けを除く）。実測が長ければ4本先取と比較する。
引き分けは同じ確定ビルドで再戦し、収入・品揃え更新・成長回数を増やさない。

## 経済の初期値

数値は全て試作値。通貨単位は仮にGとする。勝利ボーナス・利息・連勝収入は初回試作に入れない。
両者に同じ収入を渡し、フィールド支配に加えて勝者の資金まで増える循環を避ける。

|項目|提案|
|---|---|
|初期資金|12G|
|第2〜3戦の準備収入|各8G|
|第4〜6戦の準備収入|各10G|
|第7〜9戦の準備収入|各12G|
|小型レリック18・19|各2G|
|一般レリック|4〜6G|
|特殊レリック|7〜9G。個別性能で査定|
|武器|C:3G、B:5G、A:8G、S:12〜16G。プラネタリウムは16Gから比較|
|武器改造|1分岐6Gから比較。対象武器の所持・配置・改造済み条件を継承|
|拡張|4マス4G／6マス6G|
|売却|購入時の実支払額の半額、端数切り捨て。初期・フィールド品は0Gで破棄|

第5戦までの基礎収入は48G、第9戦までなら94G。拡張だけを買い続ける必要がないこと、
終盤に使い道がなくならないことを検証する。値引き・売買による増殖を防ぐため取得元と実支払額を保存する。
改造費は武器売却時に返金しない。武器を処分したら付随する改造も消去し、再購入への無料継承を防ぐ。
小型3個の6Gと一般1個の価値を比較する。レア度や面積だけで一律に価格を決めない。
プラネタリウムの価格はフィールド取得直後の強さを抑制しないため、戦闘性能の評価は別途必要。

## バッグ

最大表示6×6を維持。初期4×2の8マス、使用可能面積の上限24マスから試す。
現在の段階別自動拡張と段階5の無料拡張を廃止し、初回から毎準備1個まで購入可能にする。
4マス正方形、既存の6マスL字・3×2長方形を常設の選択肢にし、品揃え運に依存させない。
未開放セル・辺接続・上限面積を満たした配置確定時にだけ支払い、キャンセル・配置失敗は無課金。
初回は固定方向・配置後固定を継承する。回転・再配置は別の追加仕様。
面積が足りても形状が入らない場合があるため、購入前に配置プレビューを表示する。
控え8個と携行武器上限8丁は維持。控え拡張の販売はこの試作に含めない。

初期8マスは初期武器と小型品を並べやすくし、9マスのプラネタリウムには拡張投資を要求するための仮値。
24マスは全面36マス開放を避け、装備取捨選択を残すための仮値。現在の22マスより良いと確認した値ではない。

## ショップとB案UI

現在の報酬欄を価格付き商品欄に置き換える。グリッド・詳細・控えとドラッグ操作は維持する。
武器2枠、レリック3枠、対象がある場合の改造1枠を試作の基準とし、拡張は別の常設欄に置く。
初回武器はC/B/A、第3戦からSも候補にする。抽選率と各商品の確定価格は実装前にカタログ表へ定義する。
基礎品揃えは両者共通、在庫・購入・更新は各自独立。所持済み特殊品と同種武器は購入不可。
購入上限回数は設けず、資金・在庫・控え容量で制限する。購入した個体は控えへ入り、自動装備しない。
同じ商品カードから1回だけ購入でき、購入後は売り切れ表示。重複可能品は別カードなら追加購入可能。
品揃え更新は毎準備1回・2Gで通常商品を再抽選する案。更新後は別カードIDとし、同種再出現を許す。
拡張・フィールド持ち帰り候補は更新対象外。商品の取り置きは初回試作に含めない。
買い物を残したまま準備完了できる。資金不足・控え満杯・所持済み・準備確定後の購入は状態を変えず拒否。

## フィールド品

戦闘中の取得を無料とし、次準備への持ち帰りも追加料金なしとする案を推奨する。
武器は現在と同じく未所持品を控えの空き分だけ持ち帰る。同種武器の複数所持は今回追加しない。
仮レリックは次準備で1個を明示的に確保できるようにし、現在の「報酬1回消費」を取り除く。
確保は個体IDを新規発行し、特殊品の重複不可・控え容量を守る。満杯時は整理してから確保できる。
未確保のまま出撃すると失うことを表示し、品揃え更新で候補を失わせない。
引き分けでは持ち帰りも追加確定しない。無料品の売却益は0にして資金への変換を防ぐ。
ただし無料の恒久装備自体にも経済的価値がある。補給を多く取った側の連勝率を測り、偏るなら
持ち帰り上限や投下内容を比較する。有料の持ち帰りへ無断で切り替えない。

## 実装順と検証

1. 通貨・取得元・支払額・商品ID・購入/売却の不可分な更新を実装。金額不足、満杯、二重入力で資金と個体が変わらない回帰を追加。
2. 無料報酬をショップへ置換し、CPUにも同じ購入API・予算を適用。拡張を買う予算と、配置できる装備の購入を評価させる。
3. 有料拡張と5本先取を接続。勝利目標・準備番号・バッグ面積を分離し、既存の段階上限5への依存を監査。
4. フィールド確保、引き分け、最終戦、試合初期化、売却した武器の改造、在庫更新、仮個体と恒久個体を回帰検証。
5. 全自動テスト・描画・B案の実操作を確認してから、5本先取と4本先取を実プレイ比較。P9隣接効果はこの後。

評価項目は総試合時間、準備時間、完成構成で戦えた回数、拡張購入時期、残金、商品更新率、
武器別採用・勝率、補給取得差と連勝率。まず20〜30試合の傾向を見て、大きな偏りを修正する。
これだけで対人バランスを確定したとは扱わない。コード実装・自動テスト・実プレイ評価を分けて報告する。
