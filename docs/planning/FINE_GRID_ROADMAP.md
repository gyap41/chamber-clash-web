# P9前：グリッド細分化と購入経済

更新: 2026-09-11。個体ID・重複レリック・形状調整を維持し、購入経済仕様を採用した。

- レリック個体ID、18/19の+2%加算、仮取得した1個のHUD識別を維持。
- B案の58pxセル＋4px間隔、最大6×6表示、武器/レリック共通配置、控え8個・携行8丁を維持。
- 自動の段階別面積6/8/12/16/22と段階5無料拡張は廃止。初期8、購入による開放上限24を試作する。
- 正方形4マス4G・L字6マス6G・長方形6マス6Gを毎準備1個まで購入。全セル未開放・辺接続・上限を検証し、配置成功時だけ課金する。
- 拡張は各プレイヤーの bag_expansions 配列へ保存し、previousへ深いコピー。引き分け・次ラウンドで保持、試合終了でリセット。
- 所持品を控えへ購入し、取得と配置を分離。仮レリックは次準備で無料明示確保する。
- 継続使用武器は最低2マス。後続依頼でP-12/ダブルバックを1→横2マスへ変更。価格・戦闘性能は維持。
- 5本先取の勝利目標・準備番号・バッグ面積を分離する。戦闘性能は維持。

初期8は初期武器＋小型品を並べられ、9マスのプラネタリウムに拡張投資が必要になる試作値。
上限24は全面36を避け取捨選択を残す仮値。以前の22より良いと確認した値ではない。
価格/抽選率/CPUの判断理由は [購入経済仕様](PURCHASE_ECONOMY_PROPOSAL.md)。全40種の形状は [比較表](../design/ITEM_FOOTPRINT_BALANCE.md)。
