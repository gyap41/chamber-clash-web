# 階層構造・部屋種類・イベント部屋の拡張計画

[計画と提案](README.md) / [探索の工程](EXPLORATION_ROADMAP.md) / [手作り部屋の系統案](EXPLORATION_DESIGN.md#手作りの部屋構成を増やす案2026-09-27)

状態：方針採用・未実装（2026-09-30）。実装済み動作の正本はGAME_RULES。

## 経緯とユーザー決定

Enter the Gungeon第1チェンバーのマップと本編（`production_floor.gd`、生成版3）を比較した。ユーザー評価は「大分良くなったが、ボスまですぐ行けてしまう・何かが足りない」。

200seedの実測（2026-09-30）：総部屋10〜13、入口→ボス5〜7扉、分岐点ほぼ2か所、特殊部屋は宝箱2のみ。ボスまでの距離は参考例と大差なく、主因は次の2点と判断した。

- 入口が常に西端、本道が東へ直進（または1回曲がり）、ボスは東端の北。枝は南北に出て行き止まりの宝箱で終わるため、進路と寄り道が見分けられる。
- 寄り道の先の種類・部屋の大小・マップ上の目印が乏しい。

ユーザー決定：

1. **生成構造の変更は必須**：ボスの方向を固定しない、本道を曲げる、分岐を増やす。
2. **マップ表示の改善は必須**：部屋の大きさ・形と種類アイコンで描く。
3. **部屋を40種類程度へ**：大部屋を含み、イベント部屋は含まない。連絡部屋は現状不要。
4. **店などのイベント部屋を作る**。

## 現状の制約

- 手作り部屋は20種類（[制作記録](../art/production/authored-rooms/README.md)）。四方向の任意の組合せに対応するのは5種（`JUNCTIONS`）のみ。通路10種は西東、発見6種は西または東の1入口に限られる。
- 曲がる本道・多分岐には南北開口が必要。種類数より先に「開口の組合せ」が不足する。
- 全部屋が1マス。複数マスの大部屋は、生成・扉座標・マップ・カメラの対応が要る。
- 探索中の資金収入はボス報酬5Gのみ。店を置くには収入源の設計が先に要る。

## 部屋40種類の内訳案

ユーザー決定（2026-09-30）：40種類はイベント部屋を含まない数。連絡部屋（戦闘なしの十字路・通路）は現状作らない。

|区分|数|内容|
|---|---|---|
|既存20種|20|通路・発見の南北開口を、絵の向きを壊さない範囲で追加（新種類として数えない）|
|新規・1マス|14|EXPLORATION_DESIGNの6系統を基に、遊びの違う構成を追加|
|新規・大部屋|6|横2マス・縦2マス・2×2・L字など。見せ場の戦闘と到達時の広さ|

1マスと大部屋の配分は目安。イベント部屋は40種類とは別に制作し、既存20種の役割を転用して数を減らさない。

## 実装順序の案

|段階|内容|完了条件|
|---|---|---|
|1 生成版4 ✅実装済み（2026-09-30、ユーザー試遊待ち）|既存12種へ南北開口を追加し、入口・ボスの方向をランダム化。本道2〜3回の曲がり、分岐4〜6、総部屋15〜18。結果は[制作記録](../art/production/authored-rooms/README.md#開口の追加と生成版42026-09-30)|進路と寄り道を形で見分けられないこと、全seedの到達性・扉整合の検査|
|2 マップ版2|部屋の大きさ・形、種類アイコン、隣接未訪問の表示。可能なら探索中の小地図|本編で読み取りやすいことをユーザーが確認|
|3 イベントの仕組み|店と収入源、転送装置、休憩所から。既存部屋を仮の器として使う|機能の自動検査と実プレイでの手応え|
|4 大部屋対応|複数マスの生成、扉座標、カメラの引き|1種類の試作部屋で成立を確認|
|5 部屋の量産|5種類ずつ、ステージ制作テンプレートに従って制作|各部屋の制作記録と、通常倍率での確認|

段階1・2は新素材なしで進められ、「すぐ行けてしまう」感覚への効果を早く確かめられる。段階5の素材生成は、各回ごとに生成範囲をユーザーに確認する。
