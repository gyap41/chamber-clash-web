# 探索・ストーリーモード開発ロードマップ

更新: 2026-09-22。**工程と完了条件の正本**。実装済みルールは[GAME_RULES](../design/GAME_RULES.md)、検討案は[探索体験](EXPLORATION_DESIGN.md)、[ボス美術](ENEMY_BOSS_ART_PLAN.md)、[宝箱と報酬](EXPLORATION_REWARDS.md)。過去の詳細は[整理前の記録](../archive/2026-09-22/planning-cleanup/EXPLORATION_ROADMAP.md)。

## 目標と現在地

探索職人が部屋を巡り、携帯工房の装備を組み替えながらボスを目指す。死亡で今回の挑戦を終了し、装備/資金/進行をリセットする。恒久強化は後続。機械と原生生物の多様性、少し歯ごたえのある戦闘、発見と報酬の期待感を今回の設計軸とする。

P0/P1のモード分離・固定2部屋・停止する即時反映バッグ・固定拾得は実装済み。P2は生成版2の10室/6形状、四方向接続、追従カメラ、マップ、訪問/取得/攻略済み状態。P3は近接番機＋射撃トカゲの2系統、動作予告と混成、封鎖/解放・安全な敵退役まで。P4は初戦クリア保証箱・開封・取得・満杯保留まで試作。P5以降は未実装。保存はメモリ上のみ。

## 実装の順序と完了条件

| 段階 | 状態と残作業 | 完了条件 |
| --- | --- | --- |
| P0 モード分離 | 実装済み。探索とMatchStateを分離 | CPU対戦のルール・停止・所持品を混ぜない |
| P1 移動と装備 | 実装済み。手動受入は継続 | 往復や着脱で回復・弾薬・タイマーが増殖しない |
| P2 階層生成 | 基盤試作済み。P5前に前室とボスの予約配置を追加 | 多数seedで接続/室内到達性・役割数・再現性・非復活を保証 |
| P3 敵と戦闘 | 3系統中2系統。番機＋火袋トカゲは生成画像・暫定アニメーションで混成済み。突進系、編成/難度、予告の手動受入が残る | 役割差・避ける余地・読み取れる攻撃。出現/退場の参照安全と負荷 |
| P4 報酬と成長 | 初戦クリア保証箱を試作済み。残りは宝箱部屋、通常戦抽選、回復/弾薬、店、バッグ拡張。出現/開封/取得の仮演出も同時実装 | 二重取得なし、満杯でも回収可能、最低補給、成長と寄り道の意味 |
| P5 ボスと中断再開 | 前室＋南入場、まずボス1体、踏破、部屋境界セーブ。次に機械/生物の2候補化を評価 | 開始→探索→ボス→クリア/死亡を完走。復帰で再抽選・報酬増殖なし |
| P6 体験版仕上げ | 正式美術、音響、UI、導入/結末、難度、Windows/Web受入 | 目的と操作が伝わり、1階層を実機で遊べる |
| P7 拡張 | 次階層、追加ボス/敵、イベント、拠点、恒久解放 | 生態・地形・戦い方が階層ごとに変わる |

P3の最初の混成が成立した時点でP4の小さな縦切り（戦闘→箱→装備→次の部屋）を挟む。敵の数だけ先に増やさない。ボス2候補は反復性の目標案で、初回通し実装を2体完成まで止めない。新しい案は採用状態を明記してから実装する。

## システムの境界

- CombatSession：共通の移動・射撃・被弾。探索の報酬や対戦の得点は持たない。
- 探索進行：run/部屋インスタンスID、遭遇、攻略/箱/取得状態、資源、死亡/踏破。部屋クリアとrun完了を分け、相打ちは死亡優先。
- 所持品：個体・配置・控え・取得元。着脱は一括検証。武器タイマーとHPを復元し、再装備を補充にしない。
- 敵：独立定義と行動。対戦CPUの購入/装備を必須にしない。大型ボスの吸引・ノックバック・弾消しの可否は明示する。
- Actor寿命：敵退役前に弾/追射/重力場のowner参照を破棄。生きた弾を残してslotを詰めない。増援は未実装で、安全な登録境界を別途設計する。
- 生成：マップ/報酬/戦闘乱数を分離し、生成版・配置結果・ボス選択・抽選済み内容を保存対象にする。seedだけで保存を代替しない。
- 保存：Nodeや戦闘辞書の丸ごと保存を避ける。攻略と報酬を整合した単位で確定。死亡済みrunの復活、破損データによるプロフィール消去を防ぐ。戦闘中の完全復元は後続。
- 停止：バッグ/マップ/会話/店/フォーカスの理由を独立管理。閉じる入力の射撃漏れを防ぐ。
- プロフィール：将来の恒久補正は新規開始時だけ付与。部屋移動やロードごとに加算しない。

既存のEncounterResourcesは境界コピーでありセーブ形式ではない。詳細は[ARCHITECTURE](../development/ARCHITECTURE.md)。

### 戦闘UIの共通化とモード別構成

HP/弾薬/武器/行動の部品を共有し、対戦と探索の画面構成・操作許可・停止を分離済み。探索バッグとマップも接続済み。次は報酬/資金/ボス情報を対応機能と同時に追加する。オンラインの停止は探索から流用しない。最終配置・視認性・手動操作感はP6。

## 追加素材の計画

| 分類 | 必要内容 | 着手条件 |
| --- | --- | --- |
| 敵 | 機械/原生生物の役割別シルエット、動作予告、攻撃/硬直/死亡 | まず単体の挙動を仮素材で確認 |
| ボス | 通常寸法、方向、関節ピボット、分割原画と差分 | [ボス美術案](ENEMY_BOSS_ART_PLAN.md)で無地パーツの可動を試す |
| 箱 | 本体/蓋/中身、出現・開封・取得VFXとSE | [報酬案](EXPLORATION_REWARDS.md)の論理状態と同期して試作 |
| 環境 | 扉開閉・前室・生息区画の痕跡・次階層出口 | [ステージテンプレート](../art/STAGE_CREATION_TEMPLATE.md)で方向と衝突を確定 |
| 音・物語 | 必要な通知、材質音、短い導入/結末 | 既存素材を照合し、読まなくても目的を把握できること |

既存のキャラ・装備・床壁を流用する。企画の作成は画像/音の生成承認ではない。設定・予算・認証の正本をこの資料へ重複記載しない。

## 検証と調整

現行テストと実行方法は[TESTING](../development/TESTING.md)。未作成のテストを実行可能とは記載しない。

- 生成：8〜12室の役割/接続・到達性、入口の即被弾防止、家具と敵/箱の配置、大型判定、失敗時の明示的な終了。
- 状態：再訪/死亡/再挑戦/中断で敵・箱・資源の重複なし。所有者参照を次室へ持ち越さない。
- 戦闘：複数敵での近接・反撃回復・弾薬、画面外の攻撃、ボス耐性、避けた後の反撃機会。
- 表示・音：攻撃が音なしでも読める、敵弾を色以外でも識別、揺れ/点滅を抑えた設定、素材の通常倍率、音量と繰り返しの煩わしさ。
- 手動：戦闘時間、被弾理由、資源不足、整理時間、寄り道の価値、ボスの繰り返し体験。自動PASSと採用は分ける。
- 配布：敵/弾/VFX/SEの上限付近、長時間、Windows/Web。現行の終了時ObjectDB警告は別課題。
