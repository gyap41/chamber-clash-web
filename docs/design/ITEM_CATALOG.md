# アイテム・キャラクター・バッグ一覧

更新: 2026-09-12。**現在実装されている38武器・35レリック・8キャラ**の参照用一覧。
武器18種（専用初期武器8種＋通常10種）・レリック15種の追加を反映済み。詳細な発動条件は [ゲーム仕様](GAME_RULES.md) を参照。
原本は data/catalog.json、価格は scripts/catalog/shop_catalog.gd、形状は weapon_shapes.gd / relic_shapes.gd、バッグは match_state.gd / bag_expansions.gd。
特殊挙動の詳細は [ゲーム仕様](GAME_RULES.md)、面積の判断理由は [占有形状評価](ITEM_FOOTPRINT_BALANCE.md) を参照。

## バッグの範囲と形

- 最大表示は横6×縦6。初期は左上の横4×縦2（8マス）、開放面積の上限は24マス。
- 武器とレリックは同じ開放セルを使う。重なり・未開放へのはみ出し不可。回転なし。
- 控えは武器・レリック共通で8個。戦闘中の携行武器上限は8丁。控えの個数と装備の面積は別制約。
- 継続使用武器は最低2マス。形状の空白セルは占有せず、他アイテムに使える。

初期状態（O=開放、.=未開放）:

```text
OOOO..
OOOO..
......
......
......
......
```

形状は左上を基準に、`#` を占有セル、`.` を空白、`/` を改行として読む。
例: `##/#.` は `(0,0),(1,0),(0,1)` を使うL字3マス。

|形状|占有数|図（/で改行）|
|---|---:|---|
|単マス|1|`#`|
|横2|2|`##`|
|縦2|2|`#/#`|
|横3|3|`###`|
|L字3|3|`##/#.`|
|3×2|6|`###/###`|
|3×3|9|`###/###/###`|

|購入できるバッグ拡張|追加数|形状|価格|
|---|---:|---|---:|
|正方形|4|`##/##`|4G|
|L字|6|`##/##/#./#.`|6G|
|長方形|6|`###/###`|6G|

拡張は各準備1個まで。追加セルがすべて未開放・表示内で、既存領域へ辺接続し、合計24マス以内になる場所に配置する。回転なし、設置後固定。
