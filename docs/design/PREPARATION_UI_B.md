## 操作と取得

- 所持品・配置品のクリックは詳細確認。装備状態を変えず、配置モードにも入らない。
- 詳細の「配置する」で配置先クリックを開始。ドラッグでも配置でき、掴んだマスの位置を維持する。Escで取消。
- 商品説明と購入ボタンを分離。購入後は控えへ追加して詳細・色で取得品を示す。自動で配置モードに入らない。
- 詳細の「控えへ戻す」、または控え欄へドロップすると装備解除。空き枠・既存品・枠間もドロップ可能。控え満杯時は状態を変えず拒否。
- 詳細の「売却 nG」「破棄（無料品）」は解除と分け、完全に手放す。返金額は既存の実支払額の半額ルールを使う。
- 詳細には同種装備数・効果合計。クイックギアには装填倍率の追加前後を表示する。
- プレイヤー切替時は商品・配置・拡張の選択を解除する。

## バッグ拡張

グリッド下の「バッグを拡張」でゲーム内メニューを開く。再クリックまたはEscで閉じる。
正方形4マス4G、L字/長方形6マス6Gから毎準備1個まで選択し、配置先をクリックして確定する。
形の選択だけでは支払わない。成功時だけ支払い、失敗・取消は無課金。回転なし・配置後固定。
選択不可の形には資金不足・購入済み・残り面積・配置場所なしの理由を表示する。開放20マスでは正方形のみ可能、22マスでは追加できない。

## 出撃前の確認

下端にキャラ基礎HP＋装備中のHP加算、パルス、携行数、残金を表示。
武器未配置と未確保無料品の喪失警告は同時表示する。丸腰でも出撃でき、「近接のみで出撃」と明示する。
武器配置時は「この装備で出撃する」。購入・拡張は準備完了の必須条件ではない。
