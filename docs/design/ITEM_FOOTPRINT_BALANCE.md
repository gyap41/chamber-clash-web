# アイテム占有形状の方針

更新: 2026-09-11。現在は38武器・35レリック。全品の数値・価格・形状図は [アイテム一覧](ITEM_CATALOG.md)。

- 継続使用武器は最低2マス。使い捨ての例外は現在なし。初期専用8種は全て2マスで、初期4×2バッグへ収まる。
- ホチキスバーストは3連射の弾薬効率に対して横3マス。クロスステッチは4発の交差弾幕に対して2×2の4マス。
- 常時強化・防御・回復の新規レリック（ロングバレル、ワイドマガジン、ステップスプリング、パリィシェル、応急パッチ、整流コイル）は2マス。
- 条件付きの小さな効果は1マス。新規15レリックは同種重複不可。既存ミニフェザーとパワーチップは1マス・同種加算。
- S武器は原則3×2の6マス。プラネタリウムは12方向の追尾・反射弾を考慮し3×3の9マス・16G。初期8マスでは配置できず、拡張が必要。
- 追加8武器: チョークライフルは横3、ペッパーボックスは横2、ピンボールパドルとツインクレセントはL字3、スパークフォークは縦3、ベルフラワーはL字4、カーボンコピーは横4、オーロラファンは3×2の6マス。弾速・多弾・追射・設置の効率と引き換えに配置負担を分ける。
- 回転なし。横長・縦長の配置負担を残し、全形状は辺接続で連結、重複セルなし。

P-12は横2マス・3Gを維持し、発射間隔のみ0.29→0.38秒に調整した。キャラ初期武器は調整後P-12を基準とする試作値。
フィールド取得武器は控えへ入り、そのラウンドには使用できない。次の準備で配置面積を確保してから使用する。対人勝率・採用率による最終バランスは未評価。
