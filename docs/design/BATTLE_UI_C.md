# 対戦HUD C案（実装）
更新: 2026-09-12。CPU戦を主対象に、常時表示情報と下部の高さを削減した現在の仕様。画像比較案は concepts/battle-ui-2026-09-12/、正式素材への交換は [素材README](../../assets/ui/hud/README.md)。

## 配置と情報
論理画面1120×800を維持。上部パネルはy=6〜86、下部パネルはy=700〜792（92px）。回避・近接・パルスの絵は24px、待ち時間の円は直径34px。
Camera2Dの位置を(0,-90)にし、戦場を画面内で90px下へ表示する。アリーナの当たり判定、弾反射境界、移動範囲、障害物、速度は変更しない。マウス照準は既存のワールド座標変換を使う。

- 上部中央：ROUND（match_state.stage）、残り時間（切り上げ、0未満は0）、スコアと5本先取。残り10秒以下は強調色。
- 上部左右：プレイヤー/CPU・キャラ名、HP数値と割合を正確に表す連続バー。HP25%以下の数値を強調。
- 下部：自分の使用武器・装弾/予備弾・装填の進捗/残り秒数、携行武器1〜8の小アイコン、行動使用可否。所持していない武器枠は非表示。
- キー：Space回避、右クリック近接、Qパルス、R装填、E/ホイール切替。パルスは回数、回避/近接は待ち時間を表示。装填/回避による近接不可も暗くする。
- CPU戦：相手の武器名・武器一覧・弾数は表示しない。ローカル戦は下部の2行でP1/P2の弾薬と携行武器を表示し、両者の待ち時間・パルス残数を添える。
- 補給：開始時の長文を「戦闘開始」に短縮。他の取得拒否理由・補給通知は保持。危険地帯は「安全地帯 縮小中」。
- 音切替はポーズ画面。準備中は既存の音切替ボタンを維持。

## レリックとポーズ
戦闘中の自分のレリックは、仮装備・充電済み・再使用待ちの順に最大2種類を表示。同種は個数バッジへ集約する。
相手は最大4種類（同じ優先順で、残りは所持順）。両者とも「一覧」の個数は所持個体数。
戦闘中のアイコンにもツールチップはあるが、詳細確認の主導線は一覧ボタンまたはESC。

一覧ボタンで一時停止し、両者の全所持個体を最大36枚、7列のスクロール一覧で確認する。名前・効果・同種合計・待機状態はアイコンのツールチップに表示する。空き枠は表示しない。
仮装備は紫の破線枠、充電は金枠、待ち時間は暗転と秒数。重複する仮装備も個体として識別できる。
ESCまたは閉じるボタンで再開。一時停止開始・再開で射撃長押しと入力予約を解除。決着時は一覧を隠し、既存の次ラウンド/試合終了操作を維持。

## 素材と検証
レリック35種と行動3種はローカルSVGの仮素材。新しい有料画像生成/API呼び出しは行っていない。
武器は既存の武器アトラスを利用。アイコンとパネル背景はスキン設定経由で交換でき、戦闘ルールから分離している。

実行方法・検証結果は [TESTING](../development/TESTING.md)。実機の操作感、アイコンの識別性、縮小表示での読みやすさの人間による受入は残る。仮素材のドットは区別用で、レリックのランクや性能を意味しない。
