# Web比較対象・条件更新の修正

2026-09-13。比較枠が選択IDではなく前回Snapshotを優先していたため、対象追加・削除や条件変更後にも旧画像が残っていた。

修正：Snapshotの対象・条件・内容版が現在と一致するときだけ描画結果を表示。不一致時は選択中の対象のサムネイルと更新表示へ即時切替。600msの操作待ち後にGodotで最新条件を自動撮影し、進行中に条件が変わっても旧結果を画面へ戻さない。再生中の更新は最新条件の完了後に再開する。

混在比較：禁止せず配色・形状比較として案内。動作の適用対象を列挙し、レリック・ステージは静止表示と明記。静止素材だけなら再生・動作・方向・装備武器操作を無効化。

検証：TypeScript型検査・Viteビルド合格。ブラウザで4キャラから1体を除外した直後に3枠となり旧描画画像0枚、回避への条件変更後に3対象の回避表示へ自動更新した。レリック追加後に4枠へ即時切替し、実描画完了後はキャラ3体の回避とレリックの静止表示を確認。キャラを全除外した直後にレリック1枠となり再生と動作selectのdisabledを確認。再生中の背景変更直後も旧描画0枚を確認。

Godotによる撮影完了まで数秒かかる制約は継続。UIの選択反映と実描画完了を区別する。ゲーム本体は変更していない。

追加確認：再生中に背景を明→透過へ連続変更し、最終表示が透過・現在の撮影条件となり、再生ボタンが一時停止表示へ戻る（自動再開）ことを確認。その後停止した。
