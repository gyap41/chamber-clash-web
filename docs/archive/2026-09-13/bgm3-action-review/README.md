## 音楽の指定

ギター・暖かいエレキベース・タイトなドラム・短いシンセ応答を中心に変更。木の音は小さなアクセント。短い上行と応答モチーフを共通の方向に指定し、独立生成で旋律一致は保証しない。民族調の旋律／編成、洞窟的な長い残響、暗い持続音を避ける。これはプロンプトの意図であり、聴取済みの評価ではない。全文は [plan.json](plan.json)。
