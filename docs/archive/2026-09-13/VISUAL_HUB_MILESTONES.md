# Visual Hub Hybrid 実装マイルストーン

既存Godot版とゲーム原本を保持し、Godotで収集・描画、Webで一覧・比較・レビューする。
ゲームの正本は既存JSON/Resource/Scene/描画コード。レビュー情報のみ別JSONに保存する。

|段階|完了条件|状態|
|---|---|---|
|M1 現状固定|未コミット変更を確認、現在のGodot基盤を保持、対象と非対象を明記|完了|
|M2 収集・出力|型付きID/依存/UID/内容ハッシュのManifest、選択対象の実描画出力、差分キャッシュ|完了|
|M3 Webレビュー|Dashboard/Library/Board/2〜4比較/検索/詳細/タグ・承認・コメント/履歴|完了|
|M4 ローカル運用|起動・更新CLI、Godot詳細確認への受渡し、生成物分離、README|完了|
|M5 検証|更新/欠落/キャッシュ/保存/描画/ブラウザ/配布除外の検証と記録|完了|

今回はローカルHybrid基盤まで。AI生成・AI QA、汎用Dependency Graph、自動ファイル監視、
UI全状態と合成SEギャラリー、Web内のGodotリアルタイム埋込みは後続。
Web比較は生成した同条件の画像/フレーム列を使用し、任意の実時間操作はGodot版で行う。
全素材の動画生成は起動時に行わず、明示した2〜4対象だけ撮影する。

実施結果: [検証記録](VISUAL_HUB_HYBRID.md)。現行手順は tools/visual_hub/README.md。
