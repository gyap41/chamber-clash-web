# Web再生操作の修正（2026-09-13）

症状：動作を変更して再生しても以前の撮影が表示され、静止画からは再生できない。
原因：再生ボタンは保存済みフレームのタイマーを切り替えるだけで、現在の条件との差分を撮影に接続していなかった。静止画ではボタン自体を無効にしていた。

修正：再生ボタンを常時表示し、未撮影・静止画・条件や対象や原本変更の場合は24フレームを準備して自動再生。同じ条件の動画がある場合はその場で再生／一時停止する。条件変更や比較対象変更で再生を停止する。JSONキー順や微小な数値丸めで同条件を別条件と誤判定しない。準備処理の受付後に完了監視を始め、前ジョブの完了を拾わない。

今回の検証：TypeScript型検査・本番ビルド合格。ブラウザから4キャラを歩行に変更し、「再生」だけで実Godot撮影と自動再生を確認。4対象すべて24枚のPNGが異なる内容。再生中に表示フレームが進み、一時停止後に停止することを確認。ゲーム描画コードに変更はない。以前の全73回帰テストを今回の実行結果としては数えない。
