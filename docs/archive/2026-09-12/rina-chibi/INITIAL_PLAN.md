# 採用リナのゲーム用素材への差し替え

採用基準は [低頭身リナ](../../../art/settings/concepts/rina-chibi-2026-09-12/README.md)。待機・移動・回避の差し替え依頼を受領。追加生成は予算上限の変更待ち。

## 用意した生成内容

既存gpt-image-2 / high / 1024 PNG、1要求1シート、計3要求。すべて採用画像を参照し、前斜め・後ろ斜めの2方向を各シートへ収める。左右は反転で補う。

|シート|構成|プロンプト|
|---|---|---|
|待機|4コマ×2方向、4列2行|[idle](../../../art/production/first-workshop-prompts/chibi-idle.txt)|
|移動|6コマ×2方向、3列4行|[move](../../../art/production/first-workshop-prompts/chibi-move.txt)|
|回避|6コマ×2方向、3列4行|[roll](../../../art/production/first-workshop-prompts/chibi-roll.txt)|

各方向の4/6/6コマという契約を維持。3回とも候補は1つ。失敗・品質不足時に無断で追加候補を生成しない。方向ごとの頭身・顔・衣装・足元原点・歩行の左右交互運動を確認する。

## 導入と検証

原画とusageを保存し、背景透過・セル分割・全フレーム共通倍率で足元原点を統一する。静止絵は待機フレームから派生させ、別途有料生成しない。待機/移動は照準との整合、回避は実移動方向との整合を確認し、上下境界の向きのちらつきを防ぐ。採用した背面を使い、上下移動と上下照準の組み合わせを画面で確認する。

既存ピストルを独立パーツとして維持し、手元の位置と前後の描画順を調整する。カメラ、壁、衝突半径、移動速度、回避0.26秒・無敵0.31秒・速度590は維持する。

Godotインポート、対象回帰テスト、前後左右・上下移動・回避・射撃・装填の画面を確認する。自動検証と人間の操作感評価を区別する。
