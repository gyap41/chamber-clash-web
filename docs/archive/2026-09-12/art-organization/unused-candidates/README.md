# 現行ゲームには不要：削除候補の退避

今回は削除せず、以下を別保管した。設定資料・生成原画・生成履歴はここに含めていない。

|フォルダー|内容|残している理由|
|---|---|---|
|raw-frames|比較GIF作成前の連番PNG|GIFの再編集・検証に使える中間データ。現在のGIF・まとめ画像はreviewsに保存済み|
|superseded-assets|差し替え済みの旧キャラ画像・旧アニメ・ガイド|歴史的な比較ツールや報告の参照先を維持。現行ゲームでは使用しない|
|import-sidecars|生成原画の旧Godot .png.import|原画は.gdignoreでインポート対象外になり不要。移動前の状態へ戻すため保管|

ここを消しても現行ゲームに必要な素材は残る。ただし、旧比較ツール・古い資料の参照や、保存フレームからのGIF再作成には使っているため、それらを再実行する場合は復元または再撮影が必要。

[移動台帳](../relocations.json)に元パス・移動先・ハッシュを記録。[分類の入口](../../../../art/README.md)。
