# P1冒頭・戦闘UI共通化の記録

実施日: 2026-09-21。対象はUI部品の共通化と探索画面への接続。P1の部屋移動・インベントリ全体の完了記録ではない。

## 変更

HP/反撃回復と行動表示は既存部品を共有。武器情報とスロットを専用部品へ抽出し、対戦と探索の両方で使用する。読み取り専用のActor→表示値アダプターを設け、装填進捗は実効装填時間と残り時間から計算する。探索HUDは値を受け取り、武器切替・停止・SE・再挑戦・タイトル移動を要求する。許可の再検証と停止理由はゲーム側が持つ。

共通のフィールド切替からHUD更新を呼び出す箇所をモード別に差替え可能にした。対戦の既存ノードパス、準備/勝数/結果の構成は維持する。素材生成・戦闘数値変更なし。

## 検証

- shared_combat_hud：部品共有、ビューの独立、実クリック、装填/停止、8武器/丸腰、結果、探索のHUD更新。描画あり最終実行はPASS・終了コード0・標準エラー空。
- exploration_mode：開始/終了、停止、状態分離、再挑戦、対戦への復帰。動作PASS、終了時ObjectDB警告あり。
- hud_compact：対戦HUDの表示、36レリック、8武器、入力/停止。最終実行はPASS・エラーなし。
- mouse_input / rally_recovery / field_layout / result_flow / initial_preparation：動作PASS。一部に既存と同種の終了時Resource/ObjectDB解放エラーあり。

ログは `.local/shared-hud-capture.log` / `.local/shared-hud-capture-errors.log` と `.local/shared-hud-<テスト名>.log`。探索の既存テストはツール実行出力で確認した。全体回帰の再実行・人間による操作感評価・Web配布の確認はしていない。

通常1120×800、縮小840×600の画像で配置を確認。8スロットが下部パネルに収まり行動アイコンと重ならないこと、探索に対戦の時間/勝数が出ないこと、HPと回復枠、丸腰と終了画面を確認した。画像は `.local/shared-hud-*.png` に保存（ローカル検証用、Git対象外）。
