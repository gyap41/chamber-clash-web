# 待機・歩行モーションの実装記録

2026-09-21。状態遷移の分離に続く、既存素材によるモーション改善。

## 実装

BodyPlayerの状態名トラックを、胴体の回転/拡縮と左右の靴の位置トラックへ変更。
編集可能なPartsノードへSpriteを配置し、8キャラ・4方向で画像を差し替える。
身体の論理状態はStateMachinePlaybackの現在ノードから取得し、姿勢のクロスフェードと区別した。

idleは2.6秒、moveは0.52秒（移動速度/205で補正）。発進0.12秒、停止0.20秒、回避からの復帰0.10秒。
回避・死亡はstartで進行中の補間を中断し、短時間の移動/停止反転はnextで遷移待ちを解消する。
数式で残したのは方向への歩幅補正、支持足の接地補正、進行方向への減衰した傾き、武器の位置追従。
戦闘側の座標・照準・HP・弾薬・無敵・回避時間はこの処理で変更しない。

## 検証

Godot 4.7.2で以下の10テストがPASS。最終ログにSCRIPT ERROR / Assertion failedなし。

`character_motion`, `actor_animation_state`, `player_animation`, `character_animation`,
`rina_directions`, `rina_dive`, `dodge_flow`, `equipment_art`, `workshop_visuals`, `visual_hub_live`。

新規character_motionは全8人について、描画の位置/拡大率継承、呼吸の周期、4方向の足上げ、
常に少なくとも片足が支持面にあること、停止時の位置/拡縮の連続、照準の向き、武器追従の上限、
停止時計、急な再入力/回避/死亡/初期化を検証。30fpsと120fpsで傾きの応答が一致することも確認。

新規テスト初回ではπと−πの表現差により角度の直接比較が失敗したため、角度差で比較するよう修正。
実描画初回はStateMachineの親がNodeだったためActorの座標・拡大率を継承しなかった。
Node2Dへ変更し、描画位置の回帰テストを追加して再撮影した。
クロスフェード中に回避要求が待たされる問題は即時中断で修正。

Compatibility/OpenGL・NVIDIA RTX 3070 Tiで、旧式と新式の8人比較を210フレーム撮影。
待機・歩行・停止・後ろ歩きを確認し、装備付きの実戦画面も保存した。
[レビュー画像とGIF](../../art/reviews/character-motion-2026-09-21/README.md)。
再現用の撮影/パッケージ処理はtools/capture_character_motion.gdとtools/package_character_motion.py。
生フレームは`.local/rich-motion-frames/`、ログは`.local/logs/rich-*.log`。
