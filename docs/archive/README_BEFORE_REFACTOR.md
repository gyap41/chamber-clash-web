# CHAMBER CLASH Godot移行

Godot 4.5.1 / 4.7.2 Standard・GDScript・Compatibilityで検証した、ローカル2人対戦の移植版です。初期武器選択・ショップ・4枠装備・フィールド補給・全20武器の射撃処理・全12種のレリック・キャラクター選択（8キャラの能力値）・危険地帯・CPU対戦まで接続済み。HTML版の完全移植ではありません。Godot 4.5.1と4.7.2で自動テスト・Compatibility描画を確認しています。

## 起動・操作
project.godotをインポートし、F5で開始します（起動シーンはscenes/title.tscn。2026-09-08にscenes/character_select.tscnから変更）。タイトル画面には見出し・P1操作説明・「CPU対戦をはじめる」ボタンのみを表示し、ローカル2人対戦の選択肢はここには出ません（現状ローカル対戦は不要という判断のため。将来のオンライン対戦を見据え、scenes/character_select.tscnのLocal/CPU切替ボタン自体はコード・シーンとも従来のまま残しており、タイトルはcharacter_select.gdのcpu_modeをtrueに事前設定してから同シーンへ引き継いでいるだけです）。ボタンを押すとキャラクター選択（P1のみ1回、P2はP1と異なるキャラからランダム）→武器ドラフト（P1のみ）→ショップ（P1のみ、P2は自動購入）と進み、P1の操作だけで対戦が始まります。武器の説明はカードにマウスを置くと表示されます。P1が準備完了するまで戦闘・タイマーは進みません。main.tscnやcharacter_select.tscnを直接F5で開いた場合は従来どおりLocal/CPU切替やInspector既定値からの対戦も可能です。
- P1: WASD移動、マウスで狙う方向を指定、左クリック射撃、右クリック近接、Space回避、Rリロード、E銃切替、1〜4で直接装備、Gで近くの補給取得/交換、Qパルス
- P2（CPU）: キー入力を使わずCpuAI.decide()が自動操作。main.tscn単体起動やテストでキーボードから直接P2を操作する場合のキー割当は維持：矢印移動、L射撃、Shift回避、N近接、Pリロード、K銃切替、Hで近くの補給取得/交換、Oパルス
- P1はアリーナを左クリック長押しで武器の間隔に従って連射。マウスカーソルの位置が常に照準方向（狙い先の敵に自動ロックオンしない、2026-09-08変更）。UIのクリックは射撃になりません。停止・準備完了後は押し直してください。
- 両者とも画面下の武器枠クリックで装備変更可能。準備中・停止中・決着後は変更不可。
- Esc: 対戦中の一時停止。決着後Enter: 次ラウンドの初期選択へ。3勝で先取した側がマッチ勝利となり、スコアもリセットして次のマッチへ（HUDに🏆付きの専用メッセージを表示、2026-09-08変更）。
- P1はマウス照準（自動照準ではありません、2026-09-08変更）。弾倉・予備弾・変形モードは各武器に保存。切替は装填を中断し0.15秒の射撃待ち時間を付与。空弾倉で射撃すると予備弾があれば自動装填。

## パルス

P1はQ、P2はOで発動（2026-09-08の見比べ作業でP2武器切替との重複回避のためIへ変えていたことが判明し、元Web通りのOへ戻した。詳細は本計画のCHANGELOG参照）。両者ともキャラクター選択で決まる初期回数（リナ・ルナは3回、他は2回。PlayerのInitial Pulsesは未選択時の既定値）、予備パルス購入で+1。次ラウンドはキャラの初期回数へ戻ります。

使用すると全距離の敵弾・敵重力場・敵のエコードラム追射予約を即時消去し、0.65秒の無敵を付与します。自分の弾・重力場・追射予約、補給品は残ります。消去した弾から爆発・分裂・重力場は発生しません。装填中・回避中にも使用でき、装填は中断しません。敵への直接ダメージはありません。

準備中・停止中・決着後・残り0回では使用できません。キーのリピートでは連続消費せず、押し直すと1回ずつ使います。パルスリレーなどレリック連動効果・音声は未実装です。

## フィールド補給

- 対戦開始時：中央上下に同一武器、左右に弾薬箱。12秒後に左右へ同一武器と弾薬箱を補給し、その後14秒間隔。25秒に予告、30秒に中央上下へ同一Sレアを投下。
- 出現0.6秒後から取得可能。中心距離31px未満で自動取得。G/Hは65px未満の最寄りの補給を取得し、武器4枠が満杯なら装備中の1丁を交換します。古い武器は地面へ戻りません。
- 新武器は満タンで追加・自動装備。同武器はその武器の予備弾へ上限の60%（切上げ）を補給。弾薬箱は全所持武器の予備弾へ各上限の40%（切上げ）を補給。弾倉と他武器の残弾・変形状態は維持します。
- 交換は装填を中断し、交換先の変形モードを初期化します。触れるだけでは満杯時に交換しません。補給品は共用で、取得は1人1回限り。満タンで補給不要なら消費しません（同武器の満タン時も消費する元Webからの変更）。
- 未取得品は42秒で消滅。35px未満に別の未取得品がある場合は重ねて出現しません。停止中・準備中・決着後は補給も停止し、次ラウンドで全リセット。
- C/B/A/Sの抽選確率は48/30/17/5%。各レア内では全武器から同レア内で均等抽選。壁内・境界外へ編集した補給位置は出現を拒否し、自動で別位置へ移しません。

## CPU対戦

キャラクター選択画面のLocal/CPU切替ボタンで有効化します（既定はLocal）。CPUは常にP2（インデックス1）を担当し、常にP1を狙います。元WebのaiInput()/updatePlayer()のCPU分岐（legacy-web/dist/game.js）を移植したscripts/cpu_ai.gdが、毎物理フレームPlayer.step()へ渡す移動方向(dx,dy)・照準ジッター・射撃可否を決定します。CPUはキー入力を一切参照しないため、P2用の矢印/J/K/L/P/O/Hキーは無視されます（HUDの武器枠クリックもCPU側は無効）。

CPUの主な挙動：距離340px超で接近・200px未満で後退・その間は時間ベースで横移動（キーティング）。所持弾薬・レリック枠・武器4枠の空き・S武器かどうかで欲しい補給品を判定し、最寄り（S武器は距離を0.65倍して優先度を上げる）へ寄って取得。危険地帯は実際のダメージ判定（+25px）より広い余裕（+65/+60px）で検知し、アリーナ中心へ退避。自機に90px以内へ接近した敵弾は垂直方向へ避けつつ、ランダム化された0.35〜0.75秒のクールダウンごとに実際の回避ロールを発動。120px以内に敵弾が6発を超えて集中した場合はパルスを自動使用。移動先が壁にぶつかる場合は±90度/180度の候補角度で回避。武器が完全に空なら弾薬のある武器へ自動切替、リロードも自動、64px以内なら近接攻撃、射線が壁で遮られていない（または跳弾・ブーメラン武器で遮られていても構わない）場合のみ射撃。

CPU対戦では武器ドラフト・ショップもP2の実際の操作なしで進みます。P1が初期武器を選ぶと即座にP2へ同じ3候補から乱数で1丁が与えられショップへ進み（元WebのselectGun()のCPU分岐）、P1がショップの準備完了を押すと即座にP2へB/A武器（offers[0,1]、Sレアは対象外）から購入可能な1丁とレリック（offers[3,4]、予備パルスは対象外）から購入可能な1点をそれぞれ乱数で自動購入させたうえで対戦を開始します（元WebのreadyShop()のCPU分岐）。P1の左クリック自動照準操作は元Webと異なりCPU対戦でも変わりません（このGodot版の既存の意図的な差分を維持）。
