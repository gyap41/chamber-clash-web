# 8方向キャラクターリグの作り方

キャラごとに用意するのは「止まった絵のパーツ（生成画像）」と「設定ファイル」だけで、動き（走行・待機・回避・近接の体と脚、揺れ物、腕、銃・ナイフの持ち方）は共通のコードが作る。リナで作った方式を一般化したもの（2026-09-26）。経緯は [リナの制作記録](../../docs/art/reviews/rina-parts-2026-09-25/README.md)。

## 構成

|場所|役割|
|---|---|
|`characters/<name>.json`|キャラの設定：生成画像と部品の取り出し位置、向きごとの基準点、揺れ物、脚・腕の色、近接武器|
|`templates/*.txt`|生成指示の型（側面・正面＋背面・斜め・腕と手袋・近接武器）|
|`rig_builder.py` / `build.py`|設定から素材と `rig.json` を書き出す共通ビルダー|
|`landmark_picker.html`|生成画像の上をクリックして基準点を設定するページ（ブラウザー内だけで動作）|
|`data/character_rigs.json`|ゲーム側の登録（キャラID → 書き出し先）|
|`scripts/visuals/character_rig8.gd`|ゲーム側の描画（登録キャラのみ。仮組み込みは V キーで切替）|

## 新しいキャラを追加する手順

1. **生成（約5回）**：`templates/` の指示の型で、`{NAME}`・`{ONE_LINE}`・見た目の行・揺れ物の名前を書き換える。参照画像には、そのキャラのターンアラウンドと、採用済みのリナの部品画像を入れて絵柄をそろえる。1コマンド1枚、`--check` の後に実行し、失敗時は再試行しない（[AI素材生成環境ガイド](../../docs/development/ASSET_GENERATION_SETUP.md)）。
   - 側面：頭＋胴、揺れ物（腕・銃・脚なし）
   - 正面＋背面、斜め前＋斜め後ろ：同上を向きごとに
   - 腕と手袋：袖2種・握る手4種・支える手・伸ばす手2種
   - 近接武器：横向き1本（左が握り）
2. **設定ファイル**：`characters/rina.json` を写して名前・ID・書き出し先・色を変える。`landmark_picker.html` を開き、設定と生成画像を読み込んで、部品の取り出し位置（pick）と向きごとの基準点をクリックで入れ、JSONを書き出す。
   - 基準点：`ring`（頭頂の基準点）と `hem`（裾の中央下端）で大きさと位置が決まる。`shoulder_near/far`・`hand` は腕と銃。
   - 揺れ物：`swing` に任意個。`src_root`（部品側の付け根）と `attach`（体側の付け根）、`type`（`hair`＝髪・耳・尻尾、`cloth`＝布ではためく）、`channel`（揺れの基準角の系列）。付け根を動かしたいときは `style`（move/tilt/squash と、頭側の留め具を消す `erase_box`）。
   - 首の切り分け：`head_cut`（数値＝水平、折れ線＝[[x,y],...]）。頭より銃を後ろに描く向きで使う。
3. **書き出し**：`python tools/character_rig/build.py <name>`（Pillow/numpy/scipy。この環境では `PYTHONPATH=.local/video-deps`）。
4. **登録**：`data/character_rigs.json` の `rigs` に `"<ID>": "res://<書き出し先>/"` を追加し、Godot で取り込む。
5. **確認**：ゲーム中に V キーで8方向の待機・走行・回避・近接を見る。`tests/character_rig8.gd` を参考にテストを足す。

## 共通の約束

- 生成画像は白背景・1024×1024。部品どうしは離して描かせる（背景除去と連結成分で切り出す）。
- 向きの描き分けは5つ（side・diag_front・front・diag_back・back）。左向き3方向は反転。
- 大きさは頭頂の基準点〜裾の長さで全向きをそろえる。全高の基準はゲーム画素で約56。
- 脚・靴はコードで描く（色は設定）。人型以外の脚は未対応。
- 生成した素材はゲーム配布素材にする前にユーザーの採用が必要。
