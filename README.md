# CHAMBER CLASH

Godot / GDScript / Compatibilityで開発中の2D対戦ゲームです。タイトルからCPU対戦を開始できます。38武器・35レリック・8キャラクター、試合内成長と装備整理、フィールド補給、危険地帯、視覚演出・合成効果音を実装しています。P4の100ms先行入力・終盤火力調整・危険弾表示を反映済みです。

## 起動

Godotで `project.godot` をインポートし、F5で起動します。起動シーンは `scenes/ui/title.tscn` です。開発用のGodotは `.local/tools/` に配置します。プロジェクト設定は4.7系で、検証手順と互換確認は [検証ガイド](docs/development/TESTING.md) を参照してください。

「CPU対戦をはじめる」→キャラクター選択→専用初期武器のグリッド配置・任意のショップ購入→対戦と進みます。初期資金12G、ラウンド間は両者同額の収入で武器・レリック・バッグ拡張を購入します。CPU側の準備は自動です。準備が終わるまで戦闘とタイマーは進みません。5本先取でマッチ勝利です。

フィールド武器は拾うと控えへ入り、次の準備で配置してから使えます。所持済み・控え8個満杯では取得しません。

全38武器・35レリックの性能・価格・占有形状、バッグ範囲とキャラ別初期武器は [アイテム一覧](docs/design/ITEM_CATALOG.md) を参照してください。

## 操作

|操作|P1|
|---|---|
|移動|WASD|
|照準・射撃|マウス移動・左クリック長押し|
|近接・回避|右クリック・Space|
|リロード|R|
|武器切替|E、マウスホイール、1〜8、HUDの武器枠クリック|
|近くの補給取得・交換|G|
|パルス|Q|
|一時停止|Esc|
|決着後に次のラウンド/マッチへ|Enter|

準備画面はグリッド・詳細・報酬・下部控えを表示します。クリックまたはドラッグで配置した武器を携行し、武器未配置なら丸腰で出撃します。効果音は画面右上でON/OFFを切り替えます（初期はOFF、ラウンド間で設定を維持）。準備中・停止中・決着後は射撃できません。UI上のクリックは射撃にならず、停止・準備完了後は押し直してください。

装備中のレリックは画面下部の個別カードで名前と効果を確認できます。カーソルを重ねると詳しい説明、仮装備には「仮」と紫の枠を表示します。武器補給は28秒・68秒、レジェンダリーは45秒の特別投下、フィールドレリックは35秒に一度。弾薬箱で所持武器の弾を補給しながら戦います。

開発用にキャラクター選択画面のLocal/CPU切替も残しています。P2を手動操作する場合は矢印移動、L射撃、Shift回避、N近接、Pリロード、K武器切替、H補給取得、Oパルスです。任意のシーンを単体実行するキーはF6です。
