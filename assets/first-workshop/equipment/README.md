# ゲーム使用：武器・レリック

武器37 PNG（ID20以外）とレリック35 PNGを収録。ID20は既存の `../pistol.png` を使用し、全38武器・35レリックをゲームへ接続する。

武器は縦横比を保ち256×192以内、レリックは88×88以内に縮小して透明96×96の中央へ配置。戦闘では40×30を基準に個別倍率を掛け、UIでは表示枠へ収める。

`weapon_catalog.gd` の EQUIPMENT_POINTS は正規化した握り点・銃口点。握り点をローカル(8,0)に合わせ、左右反転でも保持する。発射エフェクトは銃口点を参照し、回避中は武器を隠す。弾道・性能は変更しない。

レリックは `skin.json` 経由で準備画面・HUD・フィールドへ接続する。原画・設定資料・比較画像・旧候補は保管し、配布対象から除外する。旧武器シートとレリックSVGも配布から除外する。
