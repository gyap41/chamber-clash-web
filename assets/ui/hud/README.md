# 対戦HUD素材の差し替え
現行HUDは [C案仕様](../../../docs/design/BATTLE_UI_C.md) を参照。
このディレクトリのSVGは正式素材までの仮表示。コードで作成したベクター図形で、有料生成は使用していない。

## 差し替え手順
1. 正式画像をプロジェクト内へ保存する（例 assets/ui/hud/final/）。既存仮素材は残したままでよい。
2. skin.jsonの対象キーのパスを正式画像のres://パスへ変更する。
3. Godotでインポートし、起動中のゲームを再起動する。テクスチャはゲーム中キャッシュするため、設定変更の即時反映は行わない。
4. tests/hud_compact.gdの描画確認で、小表示・一覧・仮装備枠・待ち時間・重複個数を確認する。

ゲームロジック・hud.gdの修正は不要。PNG/SVG等のTexture2Dリソースに対応。パスが見つからない場合はfallbackへ戻す。
ファイルは同名上書きでも交換できるが、正式素材を別フォルダに保存する運用を推奨。

|キー|内容|描画サイズ|
|---|---|---|
|relic_00〜relic_34|data/catalog.jsonのレリックID0〜34|戦闘28×28、一覧60×60の内側|
|dodge|回避|24×24|
|melee|近接|24×24|
|pulse|パルス|24×24|
|fallback|欠落時の共通アイコン|各表示枠|
|panel（任意）|上部・下部・一覧の共通パネル背景|8pxマージンの9分割伸縮|

## 制作条件
- レリックと行動は正方形、透過背景。PNGなら128×128程度を推奨。外周8〜12%に余裕を設け、28pxでも形が分かる図形にする。
- 名前・数字・枠・クールダウン・キー文字は画像に焼き込まない。個数、仮装備、使用不可等はコード側で重ねる。
- アイコンは色と形の両方で識別する。背景は暗色。今の仮素材のドットはIDの区別用で、性能やレア度ではない。
- panelを設定する場合は四辺8pxを伸縮しない枠として制作する。panelキーを省略すると現在のコード描画へ戻る。
- 武器画像は既存のweapon_catalog.gd/アトラス経路を利用している。skin.jsonのレリック・行動とは独立。
- Webのexport_presets.cfgはassets/ui/hud/*.jsonを含めている。skin.jsonを別の場所へ移す場合はエクスポート設定も更新する。
